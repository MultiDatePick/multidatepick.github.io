Salesforce date and time picker questions

Short answers to what admins search.

How do I add a time slot picker to a Salesforce Screen Flow?

In Flow Builder, open a Screen, search MultiDatePick, drag the Dates & Times component on and set Config Name to the config you built in the Setup Wizard. Every checkbox comes from the config. The component saves its own records when the config names a child object, or you wire Dates With Times JSON (Output) to a text variable, run the Parse Date Entries from JSON action, loop the entries and create one record each.

Can each date have different times?

Yes. Turn on Allow Different Times Per Date and every selected date gets its own time grid or dropdown, grouped by week. Leave it off and one shared grid applies the same hours to every date you picked.

Does it stop double-booking?

Yes. Conflict Behavior defaults to block: slots already taken by existing records on that calendar are grayed out and cannot be picked. Skip saves the open slots and reports the taken ones, which suits batch picking across many dates. Allow turns checking off. Conflict Look-Ahead Days sets how far ahead it checks, 360 days by default.

Can I use dropdowns instead of a time grid?

Yes. Set Time Display Mode to dropdown for start and end time pickers, or keep grid for clickable slots you can drag across. Time Interval sets the slot size in minutes, any interval you like (15, 30 or 60 are typical), and Earliest Time and Latest Time bound the day, 08:00 to 18:00 by default.

Does the Salesforce date and time picker work on Experience Cloud, App and Home pages?

Yes. On App, Home and Experience Cloud pages set Config Name plus Static Parent Record Id, the record the times belong to. On Experience Cloud, turn on Show In-Component Toast so visitors see the save confirmation.

What does the MultiDatePick Date Time component cost?

MultiDatePick is one plan at $20 per user per month with a 30-day free trial and no card required. Date Time, Date and Booking are all included, with every feature.
