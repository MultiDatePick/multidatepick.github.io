The product

What is MultiDatePick?

Three native Salesforce Lightning Web Components: Date, Date Time and Booking. Users pick many dates at once, add time slots, and book rooms, people or equipment. Every selection saves to your own Salesforce records.

Where can I use it in Salesforce?

Screen Flows, Lightning Record Pages, App Pages, Home Pages and Experience Cloud sites. Configure it once and place it anywhere.

What's the difference between the three components?

Date picks many dates, with ranges. Date Time adds time slots. Booking adds resources, capacity and conflict checks. See the component picker.

Is it only a month calendar?

No. Every component has five views: Calendar, Timeline, Week, Utilization and Agenda. All five read the same records and save the same way. See the five views.

Can different pages show different views of the same data?

Yes. The view is set per placement, so a recruiter's page can open on Week, a facilities page on Calendar and a wall display on Agenda. One install, one set of field mappings.

Can I schedule people rather than rooms?

Yes. Point the resource at User and Timeline becomes a roster, Week a shift grid and Utilization a team capacity dashboard. The Config Library has ready-made Team Capacity Planning and Staff Shift Roster setups.

Does it handle resource booking and capacity?

Yes. Booking handles one or many resources, per-slot capacity with live 3/5 badges, and conflict checks. See capacity in the User Guide.

Can I block out dates or times?

Yes. Point the component at any closure object. Block whole days, specific hours, or one resource at a time. See blocking dates.

Can I require notice, or limit how far ahead people book?

Yes. Minimum Notice (Hours) stops anything that starts too soon, and Book Up To (Days Ahead) opens a rolling window that moves forward every day. Buffer Between Bookings keeps cleanup time free after each booking. All three are checked again at Save.

Can people add a booking to Outlook or Google Calendar?

Yes. Turn on Show Add to Calendar After Saving and every save offers a calendar file (.ics) with an event for each record just saved. It opens in Outlook, Google Calendar and Apple Calendar, and works for guests on public sites. Nothing leaves Salesforce until the person downloads it. More on Add to Calendar.

Does it work on Experience Cloud sites, including public pages?

Yes. All three components are in Experience Builder, for member sites and public guest booking pages. See the guest page checklist.

Trust & security

Has it passed the Salesforce Security Review?

Yes. MultiDatePick passed the Salesforce AppExchange Security Review. Details are on Trust & Security.

Is my data stored outside Salesforce?

No. MultiDatePick is 100% native. Your data stays in your Salesforce org, with no external servers and no callouts.

Does it respect my sharing and field security?

Yes. Every read and save runs in the user's own permissions, so object access, field-level security and sharing apply to each record.

Is it accessible?

Yes. Built to WCAG 2.1 AA with keyboard support and screen-reader labels. A full VPAT 2.5 is on the accessibility page.

What languages does it support?

Nine: English, Spanish, French, German, Italian, Portuguese (Brazil), Japanese, Chinese (Simplified) and Hindi. It follows each user's Salesforce language.

Setup & ownership

Do I need Apex or a developer?

No. Admins set everything up with clicks: the Setup Wizard, Lightning App Builder and Flow Builder. Start from 40+ ready-made configs in the Config Library, and learn inside your org with the bundled guided flows: Intro to MultiDatePick and a Deep Dive for each component.

Which permission sets do I assign?

MultiDatePick - User for everyone who uses the calendars. MultiDatePick - Setup for the admins who build configs; it includes the Setup Wizard. MultiDatePick - All Access for admins who do both. MultiDatePick - Guest for the guest user of a public Experience Cloud site. Users also need access to your own objects and fields.

How long does setup take?

Minutes for a standard use case. Import a config or run the Setup Wizard, then place the component. Getting Started walks through it.

Is it a managed package?

Yes. It is a namespaced managed package, so it upgrades cleanly and never clashes with your own components. It will install from the Salesforce AppExchange at launch.

Does it work inside Salesforce Flows?

Yes. All three are Flow screen components. Set Config Name and every option comes from your saved config. A bundled Flow action turns the selection into a list you can loop over. See the Screen Flow Guide.

Pricing & availability

How much does MultiDatePick cost?

$20 per user per month, with every feature included. See pricing.

Is resource booking included, or is it an add-on?

Included. One plan with every feature: Date, Date Time and Booking. No tiers, no feature gates.

Is there a free trial?

Yes. A 30-day free trial, no card required.

When can I install it?

MultiDatePick is coming soon to the Salesforce AppExchange. Get notified at launch, and try the live demo today.

Which Salesforce editions are supported?

Any edition that supports Lightning Web Components and Screen Flows: Enterprise, Unlimited, Performance, Developer and Salesforce Platform, plus industry clouds such as Nonprofit, Education, Health, Financial Services, Public Sector and Manufacturing. Essentials and Professional are not supported because Salesforce restricts custom Lightning components there.
