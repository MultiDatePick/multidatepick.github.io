从 VS Code 部署 Flow

您已从Flow 循环文章中复制了一个入门 Flow。下面介绍如何使用 VS Code 和 Salesforce CLI 将该 Flow 部署到您的 Salesforce 组织。这是面向开发人员的方式。如果您不想使用代码编辑器，请按照屏幕 Flow（Screen Flow）指南操作：将组件放到屏幕上并设置 Config Name（配置名称）即可。

作用：复制的 XML 是一个现成的屏幕 Flow（Screen Flow），其中嵌入了 MultiDatePick 组件，并已关联一组合理的对象和字段。您只需部署一次，然后将几个 API 名称改为与您组织一致即可。第一次总共约 15 分钟，之后只需几分钟。

1. 准备工作

三个免费工具。安装一次，以后每次部署都能直接使用：

  • Visual Studio Code：代码编辑器。
  • Salesforce Extension Pack：为 VS Code 添加 SFDX 命令。在“扩展”面板中搜索“Salesforce Extension Pack”进行安装。
  • Salesforce CLI（sf）：执行部署的命令行工具。在 VS Code 终端中运行 sf version，确认已安装。

2. 一次性设置

如果您已经在使用连接到组织的 SFDX 项目，请跳过本节。

A 授权您的组织

将 VS Code 连接到您的 Salesforce 组织。打开命令面板（Ctrl/Cmd + Shift + P）并运行 SFDX: Authorize an Org，或在终端中运行：

sf org login web --alias myorg

浏览器随即打开，登录并批准即可。请先使用沙盒或 Developer 组织，不要直接用生产环境。

B 打开或创建项目

如果已有 SFDX 项目，在 VS Code 中打开其文件夹（文件 → 打开文件夹）。如果没有，请创建一个：

sf project generate --name multidatepick-flows
cd multidatepick-flows

然后在 VS Code 中打开该文件夹。您应能在资源管理器面板中看到 force-app/main/default/ 结构。

3. 导入复制的 XML

1 创建 Flow 文件

在资源管理器中展开 force-app/main/default/，打开（或创建）flows 文件夹。新建一个以 Flow 名称命名、以 .flow-meta.xml 结尾的文件，例如 On_Call_Rotation.flow-meta.xml。文件名会成为 Flow 的 API 名称，因此只能使用字母、数字和下划线。

也可以直接在 VS Code 的集成终端中创建：

# Windows (PowerShell)
New-Item force-app/main/default/flows/On_Call_Rotation.flow-meta.xml -ItemType File -Force
# macOS / Linux
mkdir -p force-app/main/default/flows && touch force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

2 粘贴并保存

将从 Flow 循环文章中复制的入门 Flow XML 粘贴到新文件中并保存（Ctrl/Cmd + S）。

3 部署到您的组织

在资源管理器中右键单击该文件并选择 SFDX: Deploy Source to Org，或在终端中运行：

sf project deploy start --source-dir force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

在“输出”面板中查看是否出现 Deploy Succeeded。如果报告字段或对象错误，属于正常情况，下一步就会修复。

4. 在 Flow Builder 中完成

4 换成您自己的对象和字段名称

在您的组织中，转到设置 → 流，打开刚部署的 Flow。查找标有 >>> UPDATE 的元素和注释，它们指向示例所假定的对象和字段 API 名称。将每一个改为与您自己的对象、日期字段和查找字段一致。然后保存并激活。

现在将 Flow 放到页面或按钮上，或直接运行，用户就可以开始选择日期了。

命令回顾： 
sf org login web --alias myorg                 # authorize once
sf project generate --name multidatepick-flows  # only if you need a new project
sf project deploy start --source-dir force-app/main/default/flows/YOUR_FLOW.flow-meta.xml
CLI 遇到问题？Salesforce 的CLI 设置指南详细介绍了安装和登录。
