容量与冲突检测：杜绝重复预订

每次保存都会与现有预订进行比对。发生冲突时如何处理，由您决定。

Block默认值。已占用的时间段无法单击，重复预订从一开始就不会发生。
Skip一次预订 20 个日期：空闲的日期会保存，横幅会列出被跳过的日期。
Allow允许重叠，适用于可以自由共享的资源。
设置项作用
容量字段资源上的一个数字。时间段在满员前都可预订，并显示 3/10 这样的实时标记
Capacity AggregationCombined 汇总多个资源（4 间各 5 座的会议室 = 20 个座位）。Distinct 将跨多间会议室的同一活动只计一次；与 Block 搭配使用，只有所有会议室都空闲时活动才会保存
Ignored Statuses已取消的预订从网格中消失，并释放所占容量
Conflict Look-Ahead Days容量标记和冲突检查向前覆盖多少天。默认 360
Buffer Between Bookings每次预订后为该资源预留的清洁或周转时间（分钟）。时间段网格、容量标记、周视图拖动和保存检查都会遵守这一设置
Book Up To (Days Ahead)滚动时间窗：从今天起向后 N 天开放预订，每天自动向前推移
Minimum Notice (Hours)不接受距现在不足 N 小时就开始的预订，保存时还会再次检查

Salesforce 预订日历常见问题

大家常搜的问题，简短作答。

Salesforce 有预订日历吗？

没有能预订您自己对象的日历。标准 Salesforce 日历可以显示事件和记录，但它只是查看工具，不是预订控件。Salesforce Scheduler 是付费附加产品，使用它自己的数据模型。MultiDatePick Booking 可为任何对象添加预订日历，并提供时间段、容量和冲突检查。

如何在 Salesforce 中预订会议室或设备？

将会议室或设备作为记录保存在任意对象上，然后在设置向导中让 MultiDatePick Booking 组件指向该对象。用户选择会议室、选择日期、单击空闲时间段即可预订。每项预订都会作为记录保存在您的预订对象上，并关联到会议室和父记录。

客户能在 Experience Cloud 站点上预订吗？

可以。将 Booking 组件拖到 Experience Cloud 页面上，设置 Config Name（配置名称）和 Static Parent Record Id，访客就能自行预订空闲时间段。访客用户可以读取和创建记录，因此取消和编辑应放在登录之后。

如何在 Salesforce 中防止重复预订？

在 Booking 组件上设置“冲突行为”。Block 让已占用的时间段无法单击；Skip 在多日期预订中保存空闲的日期，并列出被跳过的日期；Allow 允许重叠。设置容量字段后，时间段会一直开放到满员为止，并以 3/10 这样的实时标记显示。

能在 Salesforce 中查看每间会议室或每个资源的日历吗？

可以。时间轴视图将每间会议室、每辆车或每个人纵向排列，日期横向展开，并附有汇总容量条。使用率视图以热力图显示每个资源每天的占用程度，周视图则显示空闲时段。

一次预订能同时占用多个资源吗？

可以。开启 Allow Booking Multiple Resources，用户即可勾选多间会议室、多个人员或多辆车。Capacity Aggregation 决定可用性如何累计：Combined 适用于相互独立的库存，Distinct 适用于需要所有资源同时空闲的单个活动。

Salesforce 有用于预订的 Lightning Web Component 吗？

有。MultiDatePick Booking 是一个 Lightning Web Component，可用于屏幕 Flow、记录页面、应用程序页面、主页和 Experience Cloud 页面。它在设置向导中配置，无需 Apex。

MultiDatePick 预订日历多少钱？

每用户每月 $20，包含所有组件和功能，30 天免费试用，无需信用卡。
