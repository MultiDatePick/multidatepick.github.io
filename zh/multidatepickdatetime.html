Salesforce 日期和时间选择器常见问题

管理员常搜的问题，简短作答。

如何在 Salesforce 屏幕 Flow 中添加时间段选择器？

在 Flow Builder 中打开一个屏幕，搜索 MultiDatePick，把 Dates & Times 组件拖到屏幕上，并将 Config Name 设为您在设置向导中创建的配置。所有复选框都来自该配置。当配置指定了子对象时，组件会自己保存记录；或者您也可以把 Dates With Times JSON (Output) 连接到一个文本变量，运行 Parse Date Entries from JSON 操作，循环处理各条目，每条创建一条记录。

每个日期可以设置不同的时间吗？

可以。开启 Allow Different Times Per Date（允许每个日期使用不同时间），每个所选日期都会有自己的时间网格或下拉列表，并按周分组。保持关闭时，一个共用网格会为您选的每个日期应用相同的时段。

它能防止重复预订吗？

能。“冲突行为”默认为 block：该日历上已被现有记录占用的时间段会显示为灰色，无法选择。skip 会保存空闲的时间段并报告已被占用的，适合跨多个日期批量选择。allow 则关闭检查。Conflict Look-Ahead Days 设置向前检查多远，默认 360 天。

可以用下拉列表代替时间网格吗？

可以。将 Time Display Mode（时间显示模式）设为 dropdown 即使用开始和结束时间选择器，或保留 grid，使用可拖动选择的可点击时间段。Time Interval（时间间隔）以分钟为单位设置时间段长度，任意间隔均可（常见为 15、30 或 60），Earliest Time 和 Latest Time 限定一天的范围，默认 08:00 到 18:00。

Salesforce 日期和时间选择器能在 Experience Cloud、应用程序页面和主页上使用吗？

能。在应用程序页面、主页和 Experience Cloud 页面上，设置 Config Name 以及 Static Parent Record Id（这些时间所属的记录）。在 Experience Cloud 上，请开启 Show In-Component Toast，让访客看到保存确认。

MultiDatePick Date Time 组件多少钱？

MultiDatePick 只有一个方案：每用户每月 $20，30 天免费试用，无需信用卡。Date Time、Date 和 Booking 全部包含，所有功能都有。
