1从 AppExchange 安装 MultiDatePick

一个托管软件包：三个组件、设置向导和 Flow 操作。

安装在 AppExchange 列表页（上线后）单击 Get It Now。可选择仅为管理员、为所有用户或为特定简档安装。
确认“设置”中的“已安装的软件包”会列出 MultiDatePick。在 Lightning App Builder 或 Flow Builder 中搜索 MultiDatePick，可以看到 Dates、Dates & Times 和 Resource Booking。
学习软件包附带引导式 Flow：Intro to MultiDatePick，以及分别针对 Dates、Date Time 和 Booking 的 Deep Dive Flow。从设置向导中启动即可。

2分配 MultiDatePick 权限集

安装本身不会授予任何人访问权限。请在“设置”的“权限集”中分配以下其中一个。

权限集分配给
MultiDatePick - Setup负责创建配置的一两位管理员。包含设置向导。
MultiDatePick - User所有使用日历的人。不含设置向导。
MultiDatePick - All Access既创建配置又使用日历的管理员。

您自己的对象需要单独授权。用户还需要对配置所用的对象和字段拥有读取和创建权限。如果缺少权限，日历会指出具体是哪个字段或对象。

5将 MultiDatePick 添加到屏幕 Flow

在 Flow Builder 中打开一个屏幕，搜索 MultiDatePick，将组件拖上去，并设置 Config Name。

复选框来自配置。设置了 Config Name 后，您完全不必在 Flow Builder 中勾选任何复选框。仅限 Flow 的选项（Required、Show Inline、Output Date Ranges as JSON）默认关闭，除非您手动开启。

设置常见问题

管理员最先问到的问题，简短作答。

设置 MultiDatePick 需要 Apex 或开发人员吗？

不需要。安装软件包后，在设置向导中从下拉列表选择对象和字段来创建配置，再把组件放到页面或 Flow 屏幕上即可。无需 Apex。

应该分配哪个 MultiDatePick 权限集？

MultiDatePick - Setup 给负责创建配置的管理员，MultiDatePick - User 给只使用日历的人，MultiDatePick - All Access 给两者都做的管理员。用户还需要对您自己的对象和字段拥有访问权限。

为什么应用程序页面或主页上的日历没有“保存”按钮？

应用程序页面、主页和 Experience 页面没有自己的记录。把 Static Parent Record Id 设为这些日期所属的记录，“保存”按钮就会出现。

在 Flow Builder 中必须逐个设置复选框吗？

不必。把 Config Name 设为您在设置向导中保存的配置，所有复选框设置都会来自该配置。只有在不填 Config Name、手动设置属性时，才需要自己设置复选框。

可以把 MultiDatePick 配置迁移到另一个 Salesforce 组织吗？

可以。在“现有”选项卡中导出配置，然后把 JSON 粘贴到另一个组织的“导入”选项卡中。智能字段映射 (Smart Field Mapping) 让您匹配名称不同的对象或字段。
