术语

本报告中的合规级别使用以下术语（依据 ITI VPAT 2.5 模板）：

  • 支持：产品功能至少有一种方式满足该标准且无已知缺陷，或通过等效便利措施满足。
  • 部分支持：产品的部分功能不满足该标准。
  • 不支持：产品的大部分功能不满足该标准。
  • 不适用：该标准与产品无关。

WCAG 2.1 A 级

标准合规情况备注
1.1.1 非文本内容支持所有仅含图标的交互按钮（日历上一页/下一页、日期单元格、时间段、状态标签）都通过 aria-label 或 title 提供可访问名称。日期单元格的可访问名称包含完整日期和状态（例如“2026 年 4 月 1 日星期三，已选中，今天”）。
1.2.1 仅音频 / 仅视频不适用无音频或视频媒体。
1.2.2 字幕（预录）不适用无同步媒体。
1.2.3 音频描述或媒体替代不适用无视频媒体。
1.3.1 信息和关系支持日历标记使用语义化 ARIA 网格：role="grid" → role="row" → role="gridcell" + role="columnheader"。表单标签通过 lightning-input / lightning-textarea 以编程方式关联。状态标签组使用 role="group"。
1.3.2 有意义的顺序支持DOM 顺序与视觉阅读顺序一致。向导步骤按编号顺序呈现；日历各周从上到下呈现；时间段按时间顺序呈现。
1.3.3 感官特征支持说明从不只依赖颜色、形状或位置。状态标签行中的状态颜色都配有文字标签。
1.4.1 颜色的使用支持选中的日期同时显示彩色填充和粗边框环。冲突的时间段同时显示斜条纹和状态标记。
1.4.2 音频控制不适用产品不发出任何音频。
2.1.1 键盘支持所有交互元素都可通过键盘访问。方向键在日期网格中导航；Tab 在日历、状态标签和时间网格之间移动；Enter / 空格键激活获得焦点的单元格；Escape 关闭模态窗口。月份和年份箭头是 Tab 顺序中的原生按钮（0.13.0）。在五种视图中，视图切换器、每个预订横条、色块、热力图单元格和日程行都是带可访问名称的原生按钮。
2.1.2 无键盘陷阱支持焦点可通过 Tab 或 Escape 离开每个组件。模态式界面（导入/导出、保存配置）可用 Escape 关闭。
2.1.4 字符快捷键支持没有可能与辅助技术冲突的单字符快捷键。方向键 / Enter / Escape 仅作用于获得焦点的日历网格。
2.2.1 时间可调不适用不对用户交互设置任何时间限制。CMT 部署轮询会显示进度，但不对用户设时限。
2.2.2 暂停、停止、隐藏不适用没有移动、闪烁、滚动或自动更新的内容。悬停弹出框按需出现，指针离开后消失。
2.3.1 三次闪烁或低于阈值支持没有闪烁内容。部署进行中的加载图标缓慢旋转，低于闪烁阈值。
2.4.1 绕过区块支持产品是一个组件，而不是完整页面；绕过区块由 Salesforce 的“跳过导航”链接处理。
2.4.2 页面标题不适用页面标题由 Salesforce 平台设置，而非组件。
2.4.3 焦点顺序支持Tab 顺序遵循合理的 DOM 顺序：标题 → 日历网格 → 状态标签（如显示）→ 时间段网格（如显示）→ 底部按钮。
2.4.4 链接目的（上下文中）支持向导中的链接（“需要一份引导式教程？”“组件深入说明：Dates · DateTime · Booking”）都有描述性文字。悬停弹出框中的“查看记录”链接在上下文中含义清楚。
3.1.1 页面语言支持遵循用户的 Salesforce 区域设置。内置 9 种语言的翻译：英语、西班牙语、法语、德语、意大利语、日语、印地语、巴西葡萄牙语、简体中文。
3.2.1 获得焦点时支持日期单元格、状态标签或时间段获得焦点时不会引起上下文变化。只有在明确单击 / 按 Enter / 按空格键时才会选择。
3.2.2 输入时支持更改表单字段值不会自动提交。只有明确的“下一步”/“保存”/“预订”按钮才会触发提交。
3.3.1 错误识别支持表单错误（无效日期、冲突、字段级安全）通过 Toast 通知和行内错误文字显示，并使用 role="alert" 供屏幕阅读器播报。错误会指明涉及的字段、对象或规则：验证规则显示其自身的消息，缺少权限时会指明缺少什么。
3.3.2 标签或说明支持每个表单字段都有以编程方式关联的标签。多步骤操作附有行内说明文字。
4.1.1 解析支持HTML 标记格式正确；构建时由 LWC 编译器验证。（已在 WCAG 2.2 中废弃。）
4.1.2 名称、角色、值支持所有交互元素都提供可访问的名称、角色和值。日历使用 ARIA 网格模式，单元格上带 aria-selected。表单输入使用语义化的 lightning-input / lightning-textarea / lightning-combobox 组件。视图切换器是带标签的按钮组，当前视图带 aria-pressed，视图名称和标签跟随用户的语言。每个月份和年份箭头都是按其操作命名的按钮（“上个月”“下个月”）。无法选择的日期会被播报为不可用，并带有 aria-disabled。“添加到日历”控件是带可见名称的真实下载链接。axe-core 在全部八个界面上均未发现违规（见扫描结果）。

WCAG 2.1 AA 级

标准合规情况备注
1.2.4 字幕（直播）不适用无直播媒体。
1.2.5 音频描述（预录）不适用无视频媒体。
1.3.4 方向支持产品的 CSS 布局同时适应纵向和横向。无方向锁定。
1.3.5 识别输入目的支持表单字段通过 lightning-input 属性映射到已识别的输入目的。日期字段使用 type="date"，时间字段使用 type="time"。
1.4.3 对比度（最低）部分支持默认颜色与背景的对比度达到 4.5:1。状态颜色由管理员选择。白色背景上的浅色填充可能低于 4.5:1，产品无法阻止这种选择。使用 SLDS 调色板即可保持合规。自动扫描在组件内部不返回对比度结果，因此此评级基于对默认调色板的审查。
1.4.4 调整文字大小支持通过浏览器缩放，文字可放大到 200%，内容和功能不受影响。
1.4.5 文字图像支持所有文字都以真实文字呈现。界面中不使用文字图像。
1.4.10 重排部分支持日历网格和时间段网格在常见断点处重排。在 320 CSS 像素宽度下，日期网格保持 7 列结构（单元格按比例变窄，而不是变成纵向堆叠）。向导的双卡片路径选择器在 640px 以下纵向堆叠。时间轴、周和使用率是二维网格；在窄容器中，它们在可通过键盘获得焦点的区域内横向滚动。日程是单列，可正常重排。
1.4.11 非文本对比度支持交互组件的状态（焦点环、悬停、选中）使用的边框或填充颜色与相邻颜色的对比度至少为 3:1。
1.4.12 文字间距支持用户自行调整文字间距不会导致内容丢失。文字容器没有会裁切内容的固定高度。
1.4.13 悬停或获得焦点时的内容支持预订悬停弹出框可关闭（指针离开或按 Escape 关闭）、可悬停，且持续显示（获得焦点时不会自动消失）。
2.4.5 多种途径不适用产品是一个组件，而不是包含多个页面的网站。
2.4.6 标题和标签支持设置向导的步骤标签具有描述性（“名称与类型”“对象与字段”“状态与显示”“审阅与保存”）。
2.4.7 焦点可见支持所有交互元素都显示可见的焦点指示（单元格上的蓝色环、选中日期上的橙色轮廓、SLDS 按钮的焦点状态）。
2.5.1 指针手势支持拖动选择，以及在时间轴或周视图中拖动预订，都只是便捷操作；单击和记录编辑表单始终可以实现同样的效果。无需基于路径或多点的手势。
2.5.2 指针取消支持松开（而非按下）时才确定选择。在松开前将指针拖离控件即可取消。
2.5.3 名称中包含标签支持按钮的可见标签与其可访问名称一致（“保存日期”“预订”“编辑预订”）。
2.5.4 动作触发不适用产品不响应设备动作。
3.1.2 部分内容的语言支持翻译后的标签遵循用户的 Salesforce 区域设置。同一界面内不会混用多种语言。
3.2.3 一致的导航支持向导的步骤导航（下一步 / 返回）在所有路径中保持一致。底部按钮行在各组件中保持一致。
3.2.4 一致的标识支持日历的上一页/下一页箭头、状态标签颜色、容量标记和时间段图标在各组件中保持一致。
3.3.3 错误建议支持验证错误会说明如何修正。例如，导入的配置有误时会显示“JSON 无效。请检查格式后重试。”在预订时间窗的提前通知期内保存时，会列出相关日期，并提示删除这些日期或选择更晚的时间。
3.3.4 错误预防（法律、财务、数据）支持破坏性操作（删除预订）采用两次单击确认。保存默认只做新增。移除的日期绝不会被删除，除非在编辑模式中明确执行删除。
4.1.3 状态消息支持状态消息使用 role="alert"、role="status" 或 Salesforce 的 ShowToastEvent，屏幕阅读器无需移动焦点即可播报。保存后的“添加到日历”提示和许可证通知都是 role="status" 区域。

修订版 Section 508

Section 508 对软件引用 WCAG 2.0 A 级和 AA 级。WCAG 2.0 的标准是上文所报告 WCAG 2.1 标准的子集；各适用标准请参阅 WCAG 表格。

第 3 章：功能性能标准

标准合规情况备注
302.1 无视力支持可通过屏幕阅读器完整使用。ARIA 角色和标签会播报日历结构、状态和交互状态。
302.2 视力有限支持支持浏览器缩放至 200%（WCAG 1.4.4）以及用户自行调整文字间距（1.4.12）。
302.3 无法感知颜色支持颜色从不是状态的唯一指示。选中的日期带粗边框；冲突带斜条纹；状态标签包含文字。
302.4 无听力不适用产品不发出任何音频。
302.5 听力有限不适用产品不发出任何音频。
302.6 无语言能力不适用产品不需要语音输入。
302.7 操作能力有限支持可仅用单一指针或仅用键盘完整使用。无需多点触控手势。
302.8 触及范围和力量有限支持日期网格上的单击目标达到 24×24 CSS 像素的最低要求。高密度容量模式下的时间段较小，这是管理员选择的密度设置。
302.9 语言、认知和学习能力有限支持设置向导提供带行内帮助文字的引导式“引导我完成设置”路径。工具提示解释高级属性。错误消息避免使用术语行话。
