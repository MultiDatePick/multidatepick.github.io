产品

MultiDatePick 是什么？

三个原生 Salesforce Lightning Web Component：Date、Date Time 和 Booking。用户可以一次选择多个日期、添加时间段，以及预订会议室、人员或设备。每次选择都保存到您自己的 Salesforce 记录中。

可以在 Salesforce 的哪些地方使用？

屏幕 Flow（Screen Flow）、Lightning 记录页面、应用程序页面、主页和 Experience Cloud 站点。配置一次，随处放置。

三个组件有什么区别？

Date 选择多个日期，支持日期范围。Date Time 增加时间段。Booking 增加资源、容量和冲突检查。请参阅组件选择指南。

只有月历吗？

不是。每个组件都有五种视图：日历、时间轴、周、使用率和日程。五种视图读取相同的记录，以相同的方式保存。查看五种视图。

不同页面能以不同视图显示同样的数据吗？

能。视图按放置位置设置，所以招聘人员的页面可以默认打开周视图，设施页面打开日历，墙上展示屏打开日程。一次安装，一套字段映射。

能排班人员而不是会议室吗？

能。把资源指向 User，时间轴就成了值班表，周视图成了班次网格，使用率成了团队容量仪表板。Config Library 中有现成的 团队容量规划 和 员工排班表 配置。

支持资源预订和容量吗？

支持。Booking 可处理一个或多个资源、每个时间段的容量（实时显示 3/5 这样的标记）以及冲突检查。请参阅用户指南中的容量部分。

可以屏蔽日期或时间吗？

可以。将组件指向任意关闭日对象，即可屏蔽整天、特定时段，或只屏蔽某一个资源。请参阅屏蔽日期。

可以要求提前预约，或限制最多提前多久预订吗？

可以。Minimum Notice (Hours) 阻止开始时间太近的预订，Book Up To (Days Ahead) 开放一个每天向前滚动的时间窗口。Buffer Between Bookings 在每项预订后留出清场时间。这三项在保存时都会再次检查。

用户能把预订添加到 Outlook 或 Google 日历吗？

能。开启 Show Add to Calendar After Saving，每次保存后都会提供一个日历文件 (.ics)，为刚保存的每条记录各含一个事件。它可以在 Outlook、Google 日历和 Apple 日历中打开，公开站点上的访客也能使用。在用户下载之前，没有任何数据离开 Salesforce。详细了解“添加到日历”。

能用在 Experience Cloud 站点上吗，包括公开页面？

能。三个组件都可以在 Experience Builder 中使用，适用于会员站点和公开的访客预订页面。请参阅访客页面检查清单。

信任与安全

通过 Salesforce 安全审查了吗？

通过了。MultiDatePick 已通过 Salesforce AppExchange 安全审查。详情见信任与安全。

我的数据会存储在 Salesforce 之外吗？

不会。MultiDatePick 是 100% 原生应用。您的数据始终留在您的 Salesforce 组织中，没有外部服务器，也没有外部调用 (callout)。

是否遵守我的共享设置和字段安全？

是的。每次读取和保存都以用户自己的权限运行，因此对象访问权限、字段级安全和共享规则对每条记录都有效。

支持无障碍访问吗？

支持。按 WCAG 2.1 AA 标准构建，支持键盘操作并提供屏幕阅读器标签。完整的 VPAT 2.5 见无障碍页面。

支持哪些语言？

九种：英语、西班牙语、法语、德语、意大利语、巴西葡萄牙语、日语、简体中文和印地语。界面跟随每位用户的 Salesforce 语言设置。

设置与管理

需要 Apex 或开发人员吗？

不需要。管理员只需点选即可完成所有设置：设置向导、Lightning App Builder 和 Flow Builder。可以从 Config Library 中 40 多个现成配置开始，并通过内置的引导式 Flow 在您的组织内学习：Intro to MultiDatePick，以及每个组件的 Deep Dive。

需要分配哪些权限集？

MultiDatePick - User 分配给所有使用日历的人。MultiDatePick - Setup 分配给创建配置的管理员，其中包含设置向导。MultiDatePick - All Access 分配给两者都做的管理员。MultiDatePick - Guest 分配给公开 Experience Cloud 站点的访客用户。用户还需要拥有您自己的对象和字段的访问权限。

设置需要多长时间？

标准用例只需几分钟。导入一个配置或运行设置向导，然后放置组件即可。入门指南会带您一步步完成。

是托管软件包吗？

是的。它是带命名空间的托管软件包，因此升级干净利落，也绝不会与您自己的组件冲突。上线后可从 Salesforce AppExchange 安装。

能在 Salesforce Flow 中使用吗？

能。三个组件都是 Flow 屏幕组件。设置 Config Name（配置名称）后，所有选项都来自您保存的配置。内置的 Flow 操作会把选择结果转换为可循环处理的列表。请参阅屏幕 Flow 指南。

价格与上市时间

MultiDatePick 多少钱？

每用户每月 $20，包含全部功能。请参阅价格。

资源预订是包含在内，还是附加功能？

包含在内。一个方案，全部功能：Date、Date Time 和 Booking。不分档位，没有功能限制。

有免费试用吗？

有。30 天免费试用，无需信用卡。

什么时候可以安装？

MultiDatePick 即将登陆 Salesforce AppExchange。订阅上线通知，今天就可以试用在线演示。

支持哪些 Salesforce 版本？

所有支持 Lightning Web Components 和屏幕 Flow 的版本：Enterprise、Unlimited、Performance、Developer 和 Salesforce Platform，以及 Nonprofit、Education、Health、Financial Services、Public Sector 和 Manufacturing 等行业云。不支持 Essentials 和 Professional，因为 Salesforce 在这两个版本中限制自定义 Lightning 组件。
