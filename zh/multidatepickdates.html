多日期选择器常见问题

简短作答。更多内容见常见问题页面。

Salesforce 日期字段能存多个日期吗？

不能。一个标准日期字段只能存一个日期，一对字段只能存一个范围。MultiDatePick 把用户选中的每个日期都保存为父记录的相关子记录，所以一条记录可以有任意多个日期，每个日期都有自己的状态。

如何在 LWC 中选择日期范围？

把 MultiDatePick Date 组件放到页面上，拖动选中各天即可。设置 End Date Field API Name（结束日期字段 API 名称）后，相邻的日期会保存为一条带开始和结束日期的记录，周一到周五就是一条记录，而不是五条。无需自己开发 LWC。

能在屏幕 Flow 中选择多个日期吗？

能。把 Date 组件拖到 Flow 屏幕上，设置 Config Name。Selected Dates (Output) 以 ISO 日期的 Text 集合返回每个选中的日期。开启 Output Date Ranges as JSON 后，Parse Date Entries from JSON 操作会提供可循环处理的起止日期。

用户能选择循环日期吗，比如隔周的周一？

能。“添加循环模式”按钮可在开始日期和结束日期之间选择工作日、周末或自定义日期，每 N 周重复一次，还可限定为每月第 1、2、3、4 次或最后一次出现。

能在 Experience Cloud 站点上显示公开的日期日历吗？

能。把 Date 组件放到 Experience Cloud 页面上，设置 Static Parent Record Id。将 Existing Dates Mode 设为 readonly，即可显示已保存的日期而不允许访客修改；再开启 Show In-Component Toast 来显示保存消息。

MultiDatePick Date 组件多少钱？

MultiDatePick 每用户每月 $20，30 天免费试用，无需信用卡。Date、Date Time 和 Booking 组件全部包含在内。
