VS Code से Flow डिप्लॉय करें

आपने Flow loops पोस्ट से एक स्टार्टर Flow कॉपी किया है। यहाँ बताया गया है कि उस Flow को VS Code और Salesforce CLI से अपने Salesforce org में कैसे लाएँ। यह डेवलपर का रास्ता है। अगर आप कोड एडिटर नहीं छूना चाहते, तो Screen Flow गाइड देखें: कंपोनेंट को एक स्क्रीन पर डालें और Config Name सेट करें।

यह क्या करता है: कॉपी किया गया XML एक तैयार स्क्रीन फ़्लो (Screen Flow) है जिसमें MultiDatePick कंपोनेंट लगा है, और जो पहले से ऑब्जेक्ट और फ़ील्ड के एक समझदार सेट से जुड़ा है। आप इसे एक बार डिप्लॉय करते हैं, फिर कुछ API नाम अपने org के अनुसार बदलते हैं। पहली बार में कुल लगभग 15 मिनट लगते हैं, उसके बाद कुछ ही मिनट।

1. आपको क्या चाहिए

तीन मुफ़्त टूल। इन्हें एक बार इंस्टॉल करें और आगे के हर डिप्लॉय के लिए तैयार रहें:

  • Visual Studio Code: कोड एडिटर।
  • Salesforce Extension Pack: VS Code में SFDX कमांड जोड़ता है। इसे Extensions पैनल से इंस्टॉल करें ("Salesforce Extension Pack" खोजें)।
  • Salesforce CLI (sf): कमांड-लाइन टूल जिससे डिप्लॉय चलता है। VS Code के टर्मिनल में sf version चलाकर पक्का करें कि यह इंस्टॉल है।

2. एक बार का सेटअप

अगर आप पहले से अपने org से जुड़े SFDX प्रोजेक्ट में काम करते हैं, तो यह हिस्सा छोड़ दें।

A अपने org को ऑथराइज़ करें

VS Code को अपने Salesforce org से जोड़ें। Command Palette खोलें (Ctrl/Cmd + Shift + P) और SFDX: Authorize an Org चलाएँ, या टर्मिनल में यह चलाएँ:

sf org login web --alias myorg

एक ब्राउज़र खुलता है; लॉगिन करें और अनुमति दें। पहले sandbox या Developer org इस्तेमाल करें, production नहीं।

B प्रोजेक्ट खोलें या बनाएँ

अगर आपके पास SFDX प्रोजेक्ट है, तो उसका फ़ोल्डर VS Code में खोलें (File → Open Folder)। अगर नहीं, तो एक बनाएँ:

sf project generate --name multidatepick-flows
cd multidatepick-flows

फिर वह फ़ोल्डर VS Code में खोलें। Explorer पैनल में आपको force-app/main/default/ संरचना दिखनी चाहिए।

3. कॉपी किया गया XML इम्पोर्ट करें

1 Flow फ़ाइल बनाएँ

Explorer में force-app/main/default/ खोलें और flows फ़ोल्डर खोलें (या बनाएँ)। अपने Flow के नाम की नई फ़ाइल जोड़ें, जिसका अंत .flow-meta.xml से हो, उदाहरण के लिए On_Call_Rotation.flow-meta.xml। यही नाम Flow का API नाम बनता है, इसलिए केवल अक्षर, अंक और अंडरस्कोर इस्तेमाल करें।

या इसे सीधे VS Code के इंटीग्रेटेड टर्मिनल से बनाएँ:

# Windows (PowerShell)
New-Item force-app/main/default/flows/On_Call_Rotation.flow-meta.xml -ItemType File -Force
# macOS / Linux
mkdir -p force-app/main/default/flows && touch force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

2 पेस्ट करें और सहेजें

Flow loops पोस्ट से कॉपी किया गया स्टार्टर Flow XML नई फ़ाइल में पेस्ट करें और सहेजें (Ctrl/Cmd + S)।

3 अपने org में डिप्लॉय करें

Explorer में फ़ाइल पर राइट-क्लिक करके SFDX: Deploy Source to Org चुनें, या टर्मिनल में यह चलाएँ:

sf project deploy start --source-dir force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

Output पैनल में Deploy Succeeded देखें। अगर कोई फ़ील्ड या ऑब्जेक्ट त्रुटि आती है, तो यह अपेक्षित है। अगला स्टेप उसे ठीक करता है।

4. Flow Builder में पूरा करें

4 अपने ऑब्जेक्ट और फ़ील्ड के नाम डालें

अपने org में Setup → Flows पर जाएँ और अभी डिप्लॉय किया गया Flow खोलें। >>> UPDATE से चिह्नित एलिमेंट और नोट ढूँढें। ये उन ऑब्जेक्ट और फ़ील्ड API नामों की ओर इशारा करते हैं जो सैंपल ने मान लिए थे। हर एक को अपने ऑब्जेक्ट, तारीख फ़ील्ड और lookup के अनुसार बदलें। फिर Save और Activate करें।

अब Flow को किसी पेज या बटन पर लगाएँ, या सीधे चलाएँ, और यूज़र तारीखें चुनना शुरू कर सकते हैं।

कमांड का सारांश: 
sf org login web --alias myorg                 # authorize once
sf project generate --name multidatepick-flows  # only if you need a new project
sf project deploy start --source-dir force-app/main/default/flows/YOUR_FLOW.flow-meta.xml
CLI पर अटके हैं? Salesforce की CLI सेटअप गाइड में इंस्टॉल और लॉगिन विस्तार से बताए गए हैं।

Flow डिप्लॉय हो गया। आगे क्या?

लाइव डेमो में कंपोनेंट चलते हुए देखें, बिना कोड वाला Config Name तरीका सीखें, या जिस दिन MultiDatePick Salesforce AppExchange पर आए, उस दिन सूचना पाएँ।

लॉन्च पर सूचना पाएँ लाइव डेमो आज़माएँ Screen Flow गाइड

डिप्लॉय त्रुटि समझ नहीं आ रही? Support@MultiDatePick.com

Salesforce के लिए सबसे ज़्यादा कस्टमाइज़ करने योग्य कैलेंडर कंपोनेंट सुइट।
