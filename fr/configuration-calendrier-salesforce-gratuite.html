Configuration sur mesure gratuite pour votre calendrier Salesforce

Vous ne trouvez pas votre cas d'usage dans la Config Library ? Expliquez-nous comment votre équipe planifie. Nous créons une configuration MultiDatePick adaptée et vous l'envoyons gratuitement par e-mail. Vous l'importez dans l'assistant de configuration et l'associez à vos propres champs. Sans code.

  1. Vous décrivezQui réserve quoi, l'objet et ses champs, et les règles qui comptent.
  2. Nous créonsLes vues, les règles de réservation et les statuts définis pour vos utilisateurs, puis chargés dans une vraie org Salesforce.
  3. Vous importezCollez-la dans l'onglet Importer / Exporter de l'assistant de configuration et choisissez vos propres champs là où les noms diffèrent.

Envie de commencer tout de suite ? Parcourez 41 configurations prêtes à l'emploi dans la Config Library.

Questions sur la configuration gratuite

La configuration sur mesure est-elle vraiment gratuite ?

Oui. La configuration ne vous coûte rien et ne vous engage à rien. MultiDatePick lui-même coûte $20 par utilisateur et par mois, avec un essai gratuit de 30 jours.

Qu'est-ce que je reçois ?

Un fichier de configuration créé pour votre cas d'usage, avec ses vues, ses règles de réservation et ses statuts déjà définis, et une courte note expliquant comment l'importer.

Mes noms de champs doivent-ils correspondre ?

Non. À l'import, l'assistant de configuration vérifie chaque champ dans votre org et vous laisse choisir votre propre champ pour chaque nom qui diffère.

Que faut-il éviter d'envoyer ?

Les enregistrements clients, les données personnelles et les mots de passe. Les noms de champs et les paramètres nous suffisent.
