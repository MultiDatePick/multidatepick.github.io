Déployer un flux depuis VS Code

Vous avez copié un flux de démarrage depuis l'article sur les boucles de flux. Voici comment l'installer dans votre org Salesforce avec VS Code et Salesforce CLI. C'est le parcours développeur. Si vous préférez ne pas ouvrir d'éditeur de code, suivez le Guide des flux d'écran : posez le composant sur un écran et renseignez Config Name.

Ce que vous obtenez : le XML copié est un flux d'écran (Screen Flow) prêt à l'emploi qui intègre le composant MultiDatePick, déjà relié à un ensemble cohérent d'objets et de champs. Vous le déployez une fois, puis vous renommez quelques noms d'API pour qu'ils correspondent à votre org. Comptez environ 15 minutes la première fois, deux ou trois minutes ensuite.

1. Ce qu'il vous faut

Trois outils gratuits. Installez-les une fois et vous êtes prêt pour tous les déploiements suivants :

  • Visual Studio Code : l'éditeur de code.
  • Salesforce Extension Pack : ajoute les commandes SFDX à VS Code. Installez-le depuis le panneau Extensions (cherchez « Salesforce Extension Pack »).
  • Salesforce CLI (sf) : l'outil en ligne de commande qui exécute le déploiement. Vérifiez qu'il est installé en lançant sf version dans le terminal de VS Code.

2. Configuration initiale (une seule fois)

Passez cette section si vous travaillez déjà dans un projet SFDX connecté à votre org.

A Autoriser votre org

Connectez VS Code à votre org Salesforce. Ouvrez la palette de commandes (Ctrl/Cmd + Shift + P) et lancez SFDX: Authorize an Org, ou exécutez ceci dans le terminal :

sf org login web --alias myorg

Un navigateur s'ouvre : connectez-vous et validez. Commencez par une sandbox ou une Developer org, pas par la production.

B Ouvrir ou créer un projet

Si vous avez déjà un projet SFDX, ouvrez son dossier dans VS Code (File → Open Folder). Sinon, créez-en un :

sf project generate --name multidatepick-flows
cd multidatepick-flows

Ouvrez ensuite ce dossier dans VS Code. Le panneau Explorer doit afficher une arborescence force-app/main/default/.

3. Importer le XML copié

1 Créer le fichier du flux

Dans l'Explorer, dépliez force-app/main/default/ et ouvrez (ou créez) le dossier flows. Ajoutez un fichier qui porte le nom de votre flux et se termine par .flow-meta.xml, par exemple On_Call_Rotation.flow-meta.xml. Ce nom devient le nom d'API du flux : n'utilisez que des lettres, des chiffres et des tirets bas.

Ou créez-le directement depuis le terminal intégré de VS Code :

# Windows (PowerShell)
New-Item force-app/main/default/flows/On_Call_Rotation.flow-meta.xml -ItemType File -Force
# macOS / Linux
mkdir -p force-app/main/default/flows && touch force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

2 Coller et enregistrer

Collez dans le nouveau fichier le XML du flux de démarrage copié depuis l'article sur les boucles de flux, puis enregistrez (Ctrl/Cmd + S).

3 Déployer dans votre org

Faites un clic droit sur le fichier dans l'Explorer et choisissez SFDX: Deploy Source to Org, ou exécutez ceci dans le terminal :

sf project deploy start --source-dir force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

Surveillez le panneau Output jusqu'à Deploy Succeeded. Une erreur de champ ou d'objet est normale à ce stade : l'étape suivante la corrige.

4. Terminer dans Flow Builder

4 Remplacer par vos noms d'objets et de champs

Dans votre org, allez dans Configuration → Flux et ouvrez le flux que vous venez de déployer. Repérez les éléments et les notes marqués >>> UPDATE. Ils signalent les noms d'API d'objets et de champs supposés par l'exemple. Remplacez chacun par votre propre objet, votre champ date et votre champ de référence. Puis cliquez sur Enregistrer et Activer.

Placez ensuite le flux sur une page ou un bouton, ou lancez-le directement : les utilisateurs peuvent commencer à sélectionner des dates.

Récapitulatif des commandes : 
sf org login web --alias myorg                 # authorize once
sf project generate --name multidatepick-flows  # only if you need a new project
sf project deploy start --source-dir force-app/main/default/flows/YOUR_FLOW.flow-meta.xml
Bloqué sur la CLI ? Le guide d'installation de la CLI de Salesforce détaille l'installation et la connexion.

Flux déployé. Et maintenant ?

Voyez les composants fonctionner dans la démo en direct, découvrez le parcours sans code avec Config Name, ou soyez prévenu le jour où MultiDatePick arrive sur Salesforce AppExchange.
