Clique, arraste ou repita: três jeitos de escolher datas

Combine os três em uma mesma seleção. Desfazer e Limpar Tudo estão sempre a um clique.

1CliqueEscolha datas avulsas, espalhadas pelo mês.
2ArrasteArraste pelos dias para selecionar um intervalo em um só movimento.
3Padrão recorrenteDias úteis, fins de semana ou dias personalizados. A cada N semanas. A 1ª, 2ª, 3ª, 4ª ou última ocorrência do mês, como a 2ª e a 4ª sexta-feira ou o último sábado.

Selecione várias datas em um fluxo de tela

Arraste o Dates para uma tela e defina o Config Name. Cada caixa de seleção vem da sua configuração do Assistente de Configuração.

1O que você precisa antesUma variável de coleção de texto para as datas. Uma variável de texto também, se quiser intervalos.
2Coloque na telaDefina o Config Name e associe Selected Dates (Output) à sua coleção.
3O que saiAs datas na sua variável, prontas para um loop. Defina o Parent Record Id e ele também salva os registros.
SaídaO que o fluxo recebe
Selected Dates (Output)Coleção de texto com datas ISO: ["2026-07-10","2026-07-14"]
Date Ranges JSON (Output)Datas seguidas agrupadas em intervalos. Exige Output Date Ranges as JSON ativado.
Parse Date Entries from JSONAção de fluxo incluída: transforma o JSON em entradas fromDate / toDate prontas para um loop.

Configurações exclusivas de fluxo ficam desativadas até você ativá-las: Required, Show Inline (No Button) e Output Date Ranges as JSON. Os padrões completos estão no Guia de fluxo de tela.

Perguntas sobre o seletor de várias datas

Respostas curtas. Mais na página de perguntas frequentes.

Um campo de data do Salesforce pode guardar várias datas?

Não. Um campo de data padrão guarda uma data, e um par de campos guarda um intervalo. O MultiDatePick salva cada data escolhida como um registro filho relacionado ao pai, então um registro pode ter quantas datas precisar, cada uma com o próprio status.

Como selecionar um intervalo de datas em um LWC?

Coloque o componente MultiDatePick Date na página e arraste pelos dias. Defina o End Date Field API Name e os dias seguidos são salvos como um único registro com data inicial e final: de segunda a sexta vira um registro, não cinco. Nenhum LWC personalizado para construir.

Posso selecionar várias datas em um fluxo de tela?

Sim. Arraste o componente Date para uma tela do fluxo e defina o Config Name. Selected Dates (Output) devolve todas as datas escolhidas como uma coleção de texto com datas ISO. Ative Output Date Ranges as JSON e a ação Parse Date Entries from JSON entrega datas de início e fim prontas para um loop.

Os usuários podem escolher datas recorrentes, como segunda sim, segunda não?

Sim. O botão Adicionar Padrão Recorrente seleciona dias úteis, fins de semana ou dias personalizados, repete a cada N semanas e pode se limitar à 1ª, 2ª, 3ª, 4ª ou última ocorrência do mês, entre uma data inicial e uma final.

Posso mostrar um calendário público de datas em um site do Experience Cloud?

Sim. Coloque o componente Date em uma página do Experience Cloud e defina o Static Parent Record Id. Defina Existing Dates Mode como readonly para mostrar as datas salvas sem que os visitantes possam alterá-las, e ative Show In-Component Toast para as mensagens de salvamento.

Quanto custa o componente MultiDatePick Date?

O MultiDatePick custa US$ 20 por usuário por mês, com teste grátis de 30 dias e sem cartão de crédito. Os componentes Date, Date Time e Booking estão todos incluídos.
