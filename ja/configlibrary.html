Config Library

よくある日程管理のシナリオをすべてカバーする、すぐにインポートできる 41 の設定。どれも表示があらかじめ選ばれています。セットアップウィザードにコピーしたら、Lightning ページ、Experience サイト、フロー画面で Config Name（設定名） を指定するだけで使えます。項目名はワンクリックで自社の組織に対応付けられます。

初めての方は インストールと設定のガイドから始めましょう →

設定のインポートのしくみ

これらのサンプル設定は、MultiDatePick に付属するデモ用オブジェクト (Schedule__c、Event__c、Resource__c) を前提に作られています。実際の組織ではほぼ必ず独自のオブジェクト名や項目名を使っているはずですが、それで問題ありません。そのための機能が用意されています。

  1. 下のカードで [セットアップウィザード用にコピー] をクリックします。
  2. セットアップウィザードの [インポート] タブ (アプリケーションランチャー、MultiDatePick セットアップウィザード、[インポート]) に貼り付けます。
  3. 項目を対応付けます: JSON が参照するオブジェクトや項目が組織にない場合、ウィザードにスマートな項目マッピングのパネルが表示され、見つからない参照ごとに、組織内の該当するオブジェクトや項目を選べるドロップダウンが並びます。それぞれの代わりを選んで [適用してデプロイ] をクリックします。
  4. Config Name で使います: Lightning ページ、Experience サイト、フロー画面にコンポーネントを配置し、Config Name を入力します。

コードも XML の編集も不要です。ウィザードはメタデータをデプロイする前に、選んだ内容で設定を書き換えるので、インポートした設定はそのまま組織のレコードページに配置できます。すべてがすでに一致している場合 (Sandbox 間での複製など) は、対応付けの手順は自動的にスキップされます。

ぴったりの設定がない場合は、ウィザードで作りましょう。

オブジェクトと項目はすべて組織の内容で絞り込まれたドロップダウンなので、API 参照名を使わずに数分で動く設定ができます。

画面フローで使いたい場合も、同じ設定を使えます。

コンポーネントをフロー画面にドラッグし、Config Name を入力します。日付やシフトごとに 1 件ずつレコードを保存するフローについては、フローのループに関する記事をご覧ください。

1 つの設定を 5 通りの見せ方で

下の設定はどれも、デフォルトの View と Available Views（利用可能な表示） の一覧を指定しています。データ、項目、保存の動作はまったく同じで、変わるのはレイアウトだけです。ユーザーはカレンダー上部のボタンで表示を切り替えられ、どの表示を提供するかは管理者が決めます。

calendar

月間グリッド

デフォルトの表示。1 か月ずつ表示し、日ごとに状況の色を付け、クリックかドラッグで日付を選びます。「14 日には何がある?」という疑問に最適です。

timeline

縦にリソース、横に日付

デフォルトは 2 週間で、どの予約にも名前を表示する余裕があります。複数日の予約は 1 本のバーで表示されます。予約の多いリソースは 1 行にまとめられ、展開できます。

week

日 × 時間

横に 7 日間、縦に営業時間。横、縦、または両方向にドラッグして、複数の日にまたがる時間帯をまとめて選択できます。

utilization

キャパシティのヒートマップ

リソースごと・日ごとの定員の使用率を、緑から赤の色で表示します。件数ではなくパーセントで表示するには定員項目が必要です。

参照専用
agenda

時系列のリスト

今後 60 日間を、時刻と状況付きのひと目で追えるリストで表示します。引き継ぎ、毎日の打ち合わせ、スマートフォンの画面に最適です。

参照専用
デフォルトを選ぶ前に。稼働率と予定一覧は参照専用なので、予約が目的の設定のデフォルトには向きません。Available Views に入れて、デフォルトは書き込みできる表示にしてください。また、デフォルトの表示は一覧に入れなくても必ず切り替えメニューに表示されるので、Available Views に入れるのは追加する表示だけで十分です。

チームのキャパシティ計画

リソースの参照先を User にすると、コンポーネントは会議室予約ではなく人の予定管理になります。稼働率ヒートマップで開くので、マネージャーは仕事を割り当てる前に定員を超えている人を確認できます。そのあとタイムラインに切り替えて各メンバーの 1 か月を見たり、週表示で特定の時間に仕事を配置したりできます。

User をリソースにする: Resource Object API Name を User にし、Resource Filter Field IsActive を true に設定します。User には定員に当たる標準項目がないため、カスタム項目 Daily_Capacity__c を追加してください。追加しない場合、ヒートマップにはパーセントではなく件数が表示されます。User の Business Hours Start Field（営業時間開始項目） と Business Hours End Field（営業時間終了項目） で、週グリッドに各メンバーの勤務時間が反映されます。

  • Business Hours Start Field / Business Hours End Field businessHoursStartField, businessHoursEndField
  • Conflict Behavior allow conflictBehavior
  • Hover Popover Fields hoverFields

アドバイザーとの面談予約

人そのものがリソースです。アドバイザー、営業担当、コンサルタント、アカウントマネージャーがそれぞれ予約可能な行になるので、顧客との面談は会議室ではなく実際の Salesforce ユーザーに対して予約されます。30 分の面談は時刻の問題なので週表示で開きます。タイムラインでは今週空きがあるのは誰かがわかり、予定一覧は朝の打ち合わせ用に時系列で確認できます。

User をリソースにする: Resource Object API Name を User にし、カスタムのチェックボックス Is_Advisor__c で絞り込むので、選択肢には組織のすべての有効ユーザーではなくアドバイザーだけが表示されます。User の Business Hours Start Field と Business Hours End Field で各メンバーの勤務時間を設定できるので、週グリッドには実際に働いている時間が表示されます。人はダブルブッキングできないため、Conflict Behavior は block です。
主な設定
  • Resource Object API Name User resourceObjectApiName
  • Resource Filter Field (optional) Is_Advisor__c resourceFilterField
  • Booking Resource Field bookingResourceField
  • Second Picklist Field Meeting_Type__c secondStatusField
  • Conflict Behavior block conflictBehavior
  • Blocked Dates Object blockedDatesSourceObject
  • Hover Popover Fields hoverFields
表示: 週 (デフォルト) タイムライン 予定一覧 カレンダー Timeline の表示期間 14 日、Agenda Fields（予定一覧の項目）

サブブロックの活用例

Consolidate Time Span（時間範囲を統合） を有効にすると、選択した時間枠の間の空き時間が自動的に検出され、子オブジェクトに別のレコードとして保存されます。ユーザーが手動で時間枠をサブブロックに指定することもできます。

  • 休憩付きのシフト管理: 従業員が 8 時から 17 時を選ぶと、12 時から 13 時の昼休みの空き時間が Break__c オブジェクトのレコードとして自動作成されます
  • 出張の行程: ユーザーが移動の時間帯を確保すると、フライト間の乗り継ぎが Travel_Leg__c レコードになります
  • 研修のスケジュール: 講師が担当する時間帯を選ぶと、セッション間の空き時間が Available_Slot__c レコードとして保存されます
  • 予定を含む勤務スケジュール: マネージャーが勤務時間を決めると、会議や予定のための空き時間が Appointment__c オブジェクトに自動保存されます
重要: このライブラリの設定はすべて例として用意したオブジェクト名と項目名を使っています。インポートする前に、オレンジの値を自社のレコードオブジェクトと項目の API 参照名に置き換えてください。サブブロックを使う場合は、紫の値を自社の子オブジェクトと項目に置き換えます。ブロック日付を使う場合は、赤の値も置き換えます。それ以外はそのまま使えます。
