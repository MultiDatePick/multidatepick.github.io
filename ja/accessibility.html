axe はすべての対象で 2 つのチェックを手動確認対象として報告します。1 つは、Lightning のシャドウ DOM 内の ARIA の ID 参照を追跡できないことです。参照される各 ID が同じコンポーネント内に存在することは、コードレビューで確認しています。もう 1 つは、コンポーネント内のコントラストについて自動判定の結果を返さないことです。コントラストは下記の 1.4.3 で扱います。

用語

このレポートの適合レベルの値には、次の用語を使用しています (ITI VPAT 2.5 テンプレートに準拠)。

  • サポート: 製品の機能に、既知の欠陥なく達成基準を満たす方法、または同等の手段で満たす方法が少なくとも 1 つある。
  • 部分的にサポート: 製品の一部の機能が達成基準を満たしていない。
  • サポートしない: 製品の機能の大部分が達成基準を満たしていない。
  • 該当なし: 達成基準が製品に関係しない。

1.4.1 色の使用サポート選択した日付は、色の塗りつぶし「と」太い枠線の両方で表示されます。競合する時間枠は、斜めのストライプ「と」状況バッジの両方で表示されます。
1.4.2 音声の制御該当なし製品は音声を出しません。
2.1.1 キーボードサポートすべてのインタラクティブな要素にキーボードで到達できます。矢印キーで日付グリッドを移動し、Tab でカレンダー、状況ラベル、タイムグリッドの間を移動し、Enter / Space でフォーカスのあるセルを操作し、Escape でモーダルを閉じます。月と年の矢印は Tab 順序に含まれるネイティブのボタンです (0.13.0)。5 つの表示では、表示の切り替えボタン、すべての予約バー、ブロック、ヒートマップのセル、予定一覧の行が、アクセシブルな名前を持つネイティブのボタンです。
2.1.2 キーボードトラップなしサポートTab または Escape で、どのコンポーネントからもフォーカスを外せます。モーダル形式の画面 (インポート/エクスポート、設定の保存) は Escape で閉じられます。
2.1.4 文字キーのショートカットサポート支援技術と競合するおそれのある 1 文字のショートカットはありません。矢印キー / Enter / Escape は、フォーカスのあるカレンダーグリッド内でのみ有効です。
2.2.1 タイミング調整可能該当なしユーザー操作に制限時間はありません。CMT のデプロイのポーリングは、ユーザーに制限時間を課さずに進行状況を表示します。
2.2.2 一時停止、停止、非表示該当なし動く、点滅する、スクロールする、自動更新されるコンテンツはありません。ホバー時のポップオーバーは必要なときに表示され、ポインターが離れると消えます。
2.3.1 3 回の閃光、又は閾値以下サポート閃光を放つコンテンツはありません。デプロイ中のスピナーは閃光の閾値を下回る速さでゆっくり回転します。
2.4.1 ブロックスキップサポート製品はページ全体ではなくコンポーネントです。ブロックのスキップは Salesforce の「ナビゲーションをスキップ」リンクが担います。
2.4.2 ページタイトル該当なしページタイトルはコンポーネントではなく Salesforce プラットフォームが設定します。
2.4.3 フォーカス順序サポートTab の順序は論理的な DOM の順序に従います: 見出し → カレンダーグリッド → 状況ラベル (表示時) → 時間枠グリッド (表示時) → フッターのボタン。
2.4.4 リンクの目的 (コンテキスト内)サポートウィザードのリンク (「最初にガイド付きツアーを実行」、「コンポーネントのディープダイブ: Dates · DateTime · Booking」) には内容がわかるテキストがあります。ホバー時のポップオーバーにある「レコードを表示」リンクも、文脈から目的が明確です。
3.1.1 ページの言語サポートユーザーの Salesforce ロケールに従います。9 言語の翻訳を内蔵: 英語、スペイン語、フランス語、ドイツ語、イタリア語、日本語、ヒンディー語、ポルトガル語 (ブラジル)、中国語 (簡体字)。
3.2.1 フォーカス時サポート日付セル、状況ラベル、時間枠にフォーカスしても、コンテキストは変化しません。選択はクリック / Enter / Space による明示的な操作でのみ行われます。
3.2.2 入力時サポートフォームの項目値を変更しても自動送信されません。送信は「次へ」/「保存」/「予約」ボタンで明示的に行います。
3.3.1 エラーの特定サポートフォームのエラー (無効な日付、競合、項目レベルセキュリティ) は、トースト通知と、スクリーンリーダーが読み上げる role="alert" 付きのインラインエラーテキストで表示されます。エラーには関係する項目、オブジェクト、ルールが明示されます。入力規則は独自のメッセージを表示し、権限が不足している場合は何が不足しているかを示します。
3.3.2 ラベル又は説明サポートすべてのフォーム項目に、プログラムで関連付けられたラベルがあります。複数ステップの操作には、インラインの説明テキストが付いています。
4.1.1 構文解析サポートHTML マークアップは整形式で、ビルド時に LWC コンパイラーで検証されています (WCAG 2.2 では廃止)。
4.1.2 名前 (name)・役割 (role) 及び値 (value)サポートすべてのインタラクティブな要素は、アクセシブルな名前、ロール、値を公開しています。カレンダーは ARIA のグリッドパターンを使用し、セルに aria-selected を付けています。フォームの入力には、セマンティックな lightning-input / lightning-textarea / lightning-combobox コンポーネントを使用しています。表示の切り替えはラベル付きのボタングループで、選択中の表示に aria-pressed が付き、表示名とラベルはユーザーの言語に従います。月と年の矢印は、それぞれ操作名 (「前の月」、「次の月」) の付いたボタンです。選択できないカレンダーの日付は利用不可と読み上げられ、aria-disabled が付きます。「カレンダーに追加」は表示名のある本物のダウンロードリンクです。axe-core は 8 つの対象すべてで違反ゼロを検出しています (スキャン結果を参照)。

達成基準適合レベル備考

1.2.5 音声解説 (収録済)該当なし映像メディアはありません。

1.4.10 リフロー部分的にサポートカレンダーグリッドと時間枠グリッドは、一般的なブレークポイントでリフローします。幅 320 CSS ピクセルでは、日付グリッドは 7 列の構造を保ちます (縦に並び替えるのではなく、セルが比例して狭くなります)。ウィザードの 2 枚のカードによる進め方の選択は、640px 未満で縦に並びます。タイムライン、週、稼働率は 2 次元のグリッドで、狭いコンテナーではキーボードでフォーカスできる領域内で横スクロールします。予定一覧は 1 列でリフローします。
1.4.11 非テキストのコントラストサポートインタラクティブなコンポーネントの状態 (フォーカスリング、ホバー、選択) には、隣接する色に対して 3:1 以上のコントラストを持つ枠線または塗りつぶしの色を使用しています。
1.4.12 テキストの間隔サポートユーザーがテキストの間隔を上書きしても、コンテンツが失われることはありません。テキストのコンテナーには、内容が切れるような固定の高さを設定していません。
1.4.13 ホバー又はフォーカスで表示されるコンテンツサポート予約のホバー時ポップオーバーは、消去可能 (ポインターが離れる、または Escape で閉じる)、ホバー可能、かつ継続的 (フォーカス中は自動で消えない) です。
2.4.5 複数の手段該当なし製品はコンポーネントであり、複数のページを持つ Web サイトではありません。
2.4.6 見出し及びラベルサポートセットアップウィザードの手順のラベルは内容がわかるものになっています (「名前と種別」、「オブジェクトと項目」、「状況と表示」、「確認と保存」)。
2.4.7 フォーカスの可視化サポートすべてのインタラクティブな要素に、目に見えるフォーカスインジケーターがあります (セルには青いリング、選択した日付にはオレンジの輪郭線、ボタンには SLDS のフォーカス状態)。
2.5.1 ポインタのジェスチャサポートドラッグによる選択や、タイムラインや週表示での予約のドラッグは補助的な操作です。クリックとレコードの編集フォームが常に同等の手段になります。経路に基づくジェスチャや複数ポイントのジェスチャは必要ありません。
2.5.2 ポインタのキャンセルサポート選択は (押したときではなく) 離したときに確定します。離す前にポインターをコントロールの外に動かせばキャンセルできます。
2.5.3 ラベルを含む名前 (name)サポートボタンの表示ラベルはアクセシブルな名前と一致しています (「日付を保存」、「予約」、「Edit Bookings」)。
2.5.4 動きによる起動該当なし製品はデバイスの動きに反応しません。
3.1.2 一部分の言語サポート翻訳されたラベルはユーザーの Salesforce ロケールに従います。1 つの画面に複数の言語が混在することはありません。
3.2.3 一貫したナビゲーションサポートウィザードの手順の移動 (次へ / 戻る) は、どの進め方でも一貫しています。フッターのボタン行は、どのコンポーネントでも一貫しています。
3.2.4 一貫した識別性サポートカレンダーの前へ/次への矢印、状況ラベルの色、定員バッジ、時間枠のアイコンは、どのコンポーネントでも一貫しています。
3.3.3 エラー修正の提案サポート入力エラーでは何を直せばよいかを示します。たとえば不正な設定をインポートすると「無効な JSON です。形式を確認して再試行してください。」と表示されます。予約受付期間の事前通知期間内に保存しようとすると、該当する日付を示し、それを外すか、もっと後の時間を選ぶよう案内します。
3.3.4 エラー回避 (法的、金融及びデータ)サポート破壊的な操作 (予約の削除) は 2 回クリックの確認方式を使用します。保存は既定で追加のみです。外した日付は、編集モードで明示的に削除しない限り削除されません。
4.1.3 ステータスメッセージサポートステータスメッセージは role="alert"、role="status"、または Salesforce の ShowToastEvent を使用し、フォーカスを移動せずにスクリーンリーダーで読み上げられます。保存後の「カレンダーに追加」の案内とライセンスの通知は role="status" の領域です。

改正 Section 508

Section 508 は、ソフトウェアについて WCAG 2.0 のレベル A と AA を参照しています。WCAG 2.0 の達成基準は、上記で報告した WCAG 2.1 の達成基準の一部です。該当する各達成基準については WCAG の表を参照してください。

第 3 章: 機能的性能基準

達成基準適合レベル備考
302.1 視覚を使用しない場合サポートスクリーンリーダーで完全に使用できます。ARIA のロールとラベルが、カレンダーの構造、状況、操作の状態を読み上げます。
302.2 視覚が限られている場合サポートブラウザーの 200% ズーム (WCAG 1.4.4) と、ユーザーによるテキスト間隔の調整 (1.4.12) に対応しています。
302.3 色の知覚を使用しない場合サポート色だけで状態を示すことはありません。選択した日付には太い枠線、競合には斜めのストライプがあり、状況ラベルにはテキストが含まれます。
302.4 聴覚を使用しない場合該当なし製品は音声を出しません。
302.5 聴覚が限られている場合該当なし製品は音声を出しません。
302.6 発話を使用しない場合該当なし製品は音声入力を必要としません。
302.7 操作能力が限られている場合サポートシングルポインターまたはキーボードのみの入力で完全に使用できます。マルチタッチのジェスチャは必要ありません。
302.8 到達範囲と筋力が限られている場合サポート日付グリッドのクリック対象は、最小 24×24 CSS ピクセルを満たしています。高密度の定員モードでは時間枠が小さくなりますが、これは管理者が選ぶ密度の設定です。
302.9 言語、認知、学習の能力が限られている場合サポートセットアップウィザードには、インラインのヘルプテキスト付きでガイドする「手順に沿って案内してほしい」の進め方があります。ツールチップが高度なプロパティを説明します。エラーメッセージでは専門用語を避けています。
