Salesforce カレンダーを自社ブランドに: ロゴ、ブランドカラー、バナー写真

カレンダー上部のバーに自社のロゴ、名前、ブランドカラーを入れ、バナー写真も追加。ライブプレビューで変化を確かめながら設定できます。コードも CSS も不要です。

公開日 2026 年 11 月 9 日 · 更新日 2026 年 11 月 10 日 · MultiDatePick

Salesforce のカレンダーや予約ページに自社のロゴやブランドカラーを入れられますか?

はい。MultiDatePick のセットアップウィザードで、ロゴ、会社名、タイトル下の 1 行、注記を追加し、バーの色とボタンの色を選んでバナー写真を設定します。ヘッダーはすべての表示に、レコードページやアプリページ、画面フロー (Screen Flow)、ゲストが使う Experience Cloud の公開予約ページにも表示されます。コードは不要です。

「Salesforce のカレンダーに自社のロゴを入れるには?」「予約ページをブランドカラーに合わせられる?」「Experience Cloud の予約ページを自社サイトと同じ見た目にするには?」ページに置いたカレンダーコンポーネントは提供元の配色のままで、変えるにはたいていスタイルシートや静的リソース、あるいは開発者の手が必要です。

MultiDatePick なら、カレンダー上部のバーを自社ブランドに変えられます。ロゴ、名前、独自の 1、2 行のメッセージ、バーとボタンの色、そして 4 つのスタイルから選べるバナー写真。すべてセットアップウィザードの 1 つのセクションにまとまっていて、上部にライブプレビューがあります。コードも CSS も静的リソースも不要です。

できること

自社のロゴ

アップロードするか、Salesforce ファイルから画像を選ぶか、画像のリンクを貼り付けます。タイトルの左、またはタイトルの上に中央揃えで配置できます。

名前とメッセージ

カレンダーのタイトルの上に社名、その下に 1 行、さらに営業時間などの補足を表示できます。

ブランドカラー

バーの色とボタンの色。それぞれ 6 色と 5 色の色見本から選ぶか、ブランドガイドのカラーコードを入力できます。

いつでも読みやすく

「自動」はバーに合わせて暗い文字か明るい文字を選び、白い文字が載る部分はコントラスト比 4.5:1 を満たすまで色を濃くします。

バナー写真

バーの背景に、カバー写真として、暗いパネルの下に、またはバーの色で着色して。暗さ、表示位置、高さも自由に設定できます。

ゲストにも対応

アップロードしたロゴや写真には公開リンクが作成されるため、公開 Experience Cloud サイトの訪問者にも表示されます。

ロゴ、名前、メッセージを自社のものに

カレンダーのタイトルはそのまま残り、その周りに 3 行を追加できます。タイトルの上には会社やチームの名前 (最大 80 文字)、さらにタイトル下の行と補足 (それぞれ最大 160 文字) には、ページの目的や営業時間を入れます。

ロゴは高さ最大 44 px、幅最大 180 px (カバー写真では高さ 64 px) で、小さな白い背景の上に表示されるため、どんなバーの色でも見やすくなります。暗い背景向けに作られたロゴなら、ロゴの背景を白にするのチェックを外して、バーに直接載せられます。配置はタイトルの左か、ランディングページのような印象にしたいなら上部に中央揃えを選びます。

読みやすさを保つブランドカラー

バーの色は 6 色の色見本から選ぶか、ブランドのカラーコードを入力します。ボタンの色は 5 色から選ぶか、独自の色を指定します。ボタンの色は、「今日」ボタン、今日の日付の枠線、選んだ日と時間枠に使われます。バーの色が暗い色や中間の色なら、「保存」や「予約をリクエスト」などカレンダー自体のボタンや、表示切り替えで選択中の表示にも同じ色が使われます。明るいバーの場合、そこは標準のネイビーのままなので、ボタンがくっきり見えます。

バーの文字色がコントラストを管理します。自動にすると、MultiDatePick は暗いバーには白い文字、明るいバーには暗い文字と、読みやすいほうを選びます。ボタンや選択中の表示など、自社の色の上に白い文字が載る部分では、テキストに求められる WCAG AA の基準であるコントラスト比 4.5:1 を満たすのに必要な分だけ色を濃くします。自分で選びたい場合は、「明るい色」か「暗い色」を指定できます。その色では読みにくい選択にはウィザードが警告を表示し、読めない選択は「自動」に戻ります。

バナー写真は 4 つのスタイルで

バナー画像をオンにして、オフィスや建物、街の写真を追加します。次にスタイルを選びます。

  • バーの背景: 写真がバー全体に広がり、その上に文字が載ります。
  • カバー写真: 上部に横長の写真、その下にバーの色、写真の端にロゴ。プロフィールページのような見た目です。
  • パネル上にコントロールを表示: 写真全体が見え、名前とカレンダーのコントロールは暗いパネルの上に表示されます。
  • バーの色で着色: 写真をバーの色で染め、自社の色で落ち着いた印象に仕上げます。

暗さは、文字が読みやすいように写真を 0 から 90 パーセントの範囲で暗くします。明るい写真で暗さが弱く、文字が読みにくくなりそうなときは、ウィザードが警告します。着色のスタイルでは、自社の色が写真をどの程度覆うかを設定します。高さでは、バーを「コンパクト」「標準」「高め」から選べます。

公開予約ページにも自社ブランドを

ブランディングが最も重要なのは、顧客の目に触れる場所です。公開 Experience Cloud サイトではカレンダーがページそのものなので、プラグインではなく自社のページに見えるべきです。

ウィザードでアップロードした画像や Salesforce ファイルから選んだ画像には、公開リンクが作成されます。ログインしないゲストにも、ページが提供するすべての表示でロゴと写真が表示されます。

ページ自体の設定は、クリック操作だけの 5 ステップです。Experience Cloud で公開予約ページを作る方法はこちら。

狭い画面にも対応

スマートフォンではバーの幅が狭くなり、写真は収まるように切り抜かれます。常に表示する部分で、画面に残す部分を中央、上、下、左、右から選べます。街並みや店舗の外観、キャンパスが画面からはみ出すことはありません。

セットアップウィザードで設定する

コードも CSS も静的リソースも不要。手順は 4 つです。

  1. 「その他の設定」を開きます。 MultiDatePick セットアップウィザードで設定の「その他の設定」タブを開き、ヘッダーセクションを探します。上部にライブプレビューがあります。
  2. ロゴとテキストを追加します。 ロゴをアップロードするか、Salesforce ファイルから画像を選ぶか、リンクを貼り付けます。続いて「名前」「タイトル下の行」「補足」を入力します。
  3. 色を選びます。 バーとボタンの色見本をクリックするか、カラーコードを入力します。「バーの文字色」は「自動」のままにしておきます。
  4. 写真を追加して保存します。 「バナー画像」をオンにし、写真とスタイルを選びます。「確認」ステップでヘッダーをもう一度確かめてから、設定を保存します。その Config Name を使うすべてのページで、次の読み込みから新しいヘッダーが表示されます。

管理者が設定するまで、誰の画面も変わりません。ヘッダーを設定していないカレンダーは標準のバーのままです。

App Builder で設定したいときは、同じ設定が 1 つのプロパティ Header (ヘッダー) にまとまっていて、Dates、Dates & Times、Resource Booking の 3 つのコンポーネントすべてで使えます。レコードページ、アプリケーションページ、ホームページ、Experience Cloud のページ、フロー画面に対応しています。

カレンダーをブランド化しているチーム

顧客、会員、スタッフが毎日目にするカレンダーなら、どれにも向いています。

ファイナンシャルアドバイザー顧客がすでに信頼しているロゴと会社の色で、顧客向けの予約ページを。
クリニック・医院クリニック名を掲げ、補足に診療時間を載せた予約ページ。
大学学業相談や個別指導の予約をスクールカラーで。バーの背景にはキャンパスの写真を。
複数拠点のブランド拠点ごとに 1 つの設定を用意し、それぞれ独自の写真と名前に。ブランドカラーはすべて共通です。
非営利団体団体のロゴと活動現場の写真を掲げたボランティア募集ページ。
社内アプリホームページのカレンダーを会社の色に。後付けのツールではなく、アプリの一部に見えます。

動作を決める設定

どれもセットアップウィザードの「ヘッダー」セクションにあるコントロールです。App Builder、Experience Builder、Flow Builder では、1 つのプロパティ Header (headerStyle) に JSON としてまとめて入ります。JSON はウィザードが書き出します。たとえば{"logo":"https://...","name":"ACME Financial","band":"#14532D","button":"#FBBF24"}.

よくある質問

Salesforce のカレンダーや予約ページに自社のロゴやブランドカラーを入れられますか?

はい。MultiDatePick のセットアップウィザードで、ロゴ、会社名、タイトル下の 1 行、注記を追加し、バーの色とボタンの色を選んでバナー写真を設定します。ヘッダーはすべての表示に、レコードページやアプリページ、画面フロー (Screen Flow)、ゲストが使う Experience Cloud の公開予約ページにも表示されます。コードは不要です。

Salesforce カレンダーにロゴを追加するには?

MultiDatePick セットアップウィザードを開き、「その他の設定」にある「ヘッダー」セクションを使います。ロゴをアップロードするか、Salesforce ファイルから画像を選ぶか、画像のリンクを貼り付けてください。ロゴは高さ最大 44 px で、カレンダーのタイトルの左、またはタイトルの上に中央揃えで表示されます。設定を保存すれば、その設定を使うすべてのページにロゴが表示されます。コードも CSS も不要です。

Salesforce の予約カレンダーを自社のブランドカラーに合わせられますか?

はい。バーの色とボタンの色を色見本から選ぶか、ブランドのカラーコードを入力します。「バーの文字色」を「自動」にしておけば、MultiDatePick がその色の上で読みやすいほうの文字色 (暗い色か明るい色) を選びます。白い文字が載る部分は、コントラスト比 4.5:1 を満たすまで色を濃くします。

Experience Cloud サイトのゲストにも、ロゴやバナー写真は表示されますか?

はい。ウィザードでアップロードした画像や Salesforce ファイルから選んだ画像には公開リンクが作成されるため、ログインしない訪問者にも表示されます。Salesforce 標準の公開リンクなので、[設定] で「コンテンツ配信および公開リンク」を有効にしておく必要があります。

ほかの Web サイトの画像リンクも使えますか?

はい。https で始まる画像リンクなら、どれでも貼り付けられます。ほかの Web サイトの画像を Salesforce で表示するには、そのサイトを [設定] の「信頼済み URL」に追加します。画像をアップロードすれば、この手順は不要です。リンク先の画像が読み込めなかった場合、カレンダーは画像なしでバーを表示し、ウィザードがリンクの下でお知らせします。

ヘッダーは画面フロー (Screen Flow) やアプリケーションページでも使えますか?

はい。ヘッダーは Dates、Dates & Times、Resource Booking の 3 つのコンポーネントすべてにある設定で、レコードページ、アプリケーションページ、ホームページ、Experience Cloud のページ、フロー画面で使えます。セットアップウィザードで設定して Config Name を使うか、App Builder、Experience Builder、Flow Builder の Header (ヘッダー) プロパティに JSON を貼り付けます。
