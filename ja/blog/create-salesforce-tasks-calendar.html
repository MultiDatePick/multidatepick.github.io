Salesforce の ToDo をカレンダーで一括作成: 日を選んで、保存は 1 回だけ

ToDo が必要な日をすべてクリックし、件名を入力して保存。1 日に 1 件の標準 Salesforce ToDo が、レコードに関連付けて作成されます。フローも Apex もコードも不要です。

公開日 2026 年 11 月 8 日 · MultiDatePick

「同じ ToDo を複数の日付に作成するには?」「Salesforce で ToDo をまとめて作成できる?」「自分の ToDo をカレンダーで見るには?」「新規 ToDo」ボタンで保存できるのは、期日が 1 つの ToDo 1 件だけです。繰り返し ToDo は決まった周期でしか繰り返せません。選んだ 4 日にフォローアップの電話を 4 回入れる計画でも、同じフォームを 4 回入力することになります。

MultiDatePick は、レコードページにカレンダーを置きます。日をクリックし、件名を入力して保存すれば、1 日に 1 件の Salesforce ToDo が作成されます。どれもレコードに関連付けられ、状況、優先度、コメントも入力済みです。普通の ToDo なので、活動タイムライン、レポート、すべてのリストビューに表示されます。フローも Apex も不要です。

できること

1 日に 1 件の ToDo

クリックした日がそれぞれ 1 件の ToDo になり、その日が期日になります。10 日なら 10 件、保存は 1 回です。

レコードに関連付け

各 ToDo はページのレコードに関連付けられます。取引先、商談、ケース、カスタムレコード、または対象の取引先責任者やリードです。

項目は自動で入力

入力した件名、選んだ状況、さらに優先度やコメントなどほかの項目も、新しい ToDo すべてに入力されます。

どんな日でも

飛び飛びの日をクリック、連続する日をドラッグ、または隔週の火曜日のような繰り返しパターンを追加できます。

カレンダーで ToDo を確認

既存の ToDo は状況の色で表示されます。日にカーソルを合わせると件名と状況が表示され、各日に件名を書き込むこともできます。

あとから変更

編集モードでは、ToDo を別の日に移動したり、状況を変えたり、削除したりできます。1 件ずつでも、まとめてでも操作できます。

日を選んで、保存は 1 回

カレンダーはレコードページに置かれ、そのレコードにすでにある ToDo を状況の色で表示します。顧客フォローアップを何回か計画する手順は 4 つです。

  1. 日をクリックします。 ToDo が必要な日をそれぞれ選びます。選んだ日はオレンジ色になり、もう一度クリックすると選択が外れます。
  2. 件名を入力します。 「レコードのラベル」欄に、新しい ToDo すべての件名 (例: 顧客フォローアップ) を入力します。
  3. 状況を選びます。 Not Started、In Progress など、ToDo の「状況」選択リストにある値ならどれでも選べます。
  4. 保存します。 1 日に 1 件の ToDo が作成され、レコードに関連付けられます。選んだ日はすぐに状況の色に変わります。

日にカーソルを合わせると、その ToDo の件名と状況が表示され、そこから ToDo を開けます。「1 日に複数を許可」をオンにすれば、すでに ToDo がある日にもう 1 件追加できます。

ポップアップで ToDo の詳細をすべて入力

件名と状況だけでは足りないこともよくあります。セットアップウィザードでレコード詳細のポップアップをオンにすると、「ToDo を作成」を押したときに、選んだ項目の入力フォームが先に開きます。優先度やコメントなど、ToDo のどの項目でも追加できます。選んだすべての日に同じ内容を入力することも、日ごとに切り替えて 1 日だけ別の件名にし、残りの日は共通の内容のままにすることもできます。

表示する項目、必須にする項目、デフォルト値、項目の幅は、すべてウィザードの「項目」画面で決めます。日をクリックした瞬間にポップアップを開き、ToDo を 1 件ずつ作成することもできます。表示されるのは、その人が作成時に入力できる項目だけで、Salesforce で必須の項目には必須マークが付きます。

活動タイムラインに表示される、本物の Salesforce ToDo

コピーでもカスタムオブジェクトでもありません。各日は標準の ToDo として保存されるため、チームが手作業で作成した ToDo と同じように扱われます。レコードの活動タイムライン、ToDo タブ、レポートやリストビュー、任命先の ToDo リストに表示されます。取引先責任者やリードでは名前で、取引先、商談、ケース、カスタムオブジェクトでは関連先で紐づきます。

すべての ToDo を 1 つのカレンダーに

同じコンポーネントが ToDo カレンダーとしても使えます。アプリケーションページやホームページで「すべてのレコードを表示」(Show All Records) をオンにすると、自分が参照できるすべての ToDo が表示されます。OwnerId=ME のような「レコードフィルター」(Record Filter) を加えれば、各ユーザーには自分の ToDo だけが表示されます。「各日にレコード名を表示」(Show Record Names in Each Day) をオンにすると、各日に件名が状況の色で書き込まれ、カレンダー上部の状況ピルで状況ごとに絞り込めます。

取引先の取引先責任者や商談に ToDo が分散していませんか? 積み上げ項目 (Rollup Field) を使えば、それらも取引先のカレンダーに表示できます。取引先カレンダーで関連レコードを表示する方法をご覧ください。

日付にパターンがあるとき

繰り返す ToDo の計画もあります。隔週火曜の電話、毎月最終金曜のレポート、第 2・第 4 金曜のレビューなどです。繰り返しパターンを追加を使えば、それらの日を自動で入力し、追加する前に日付を表示し、設定した終了日で止まります。各日はそれぞれ別の ToDo として保存されるので、1 件だけ移動したり取りやめたりしても、ほかには影響しません。

ほかのパターンや、日付範囲では表せない理由は、Salesforce で繰り返しの日付パターンを扱うで解説しています。

セットアップウィザードで設定する

コードも、作成するフローも不要です。セットアップウィザードが設定を書き込み、コンポーネントがそれを読み込みます。

  1. カレンダーの配置場所を選びます。 MultiDatePick セットアップウィザードのタブを開き、レコードページ (ここでは取引先) と、保存方法として日付ごとに 1 件のレコードを選びます。
  2. 選んだ日を ToDo として保存するよう設定します。 「項目」画面で ToDo をクリックし、ページとの関連付けを確認します。取引先なら 関連先 ID (WhatId)、取引先責任者やリードなら 名前 ID (WhoId) です。期日 (ActivityDate) と 件名 はウィザードが自動で入力します。
  3. 残りを入力します。 既定の件名を入力し、件名をすっきり保つため「レコード名に日付/時刻を追加」のチェックを外し、「既定の項目値」に Priority=High などを入力します。Account_Tasks のような名前で設定を保存します。
  4. ページにコンポーネントを配置します。 Lightning App Builder で、取引先ページに MultiDatePick の Dates コンポーネントを追加し、Config Name に設定名を入力します。

状況の色は ToDo の状況の値ごとに決まるため、Completed は緑、Deferred はグレーにできます。あとで設定を変更すると、その設定を使うすべてのページに次回の読み込みから反映されます。

この方法で ToDo を作成しているチーム

期日が 1 つではなく、選んだ数日に予定がある計画なら、どんな業務にも使えます。

アカウントマネージャー1 年分の四半期ごとのフォローアップや現地訪問を、取引先でまとめて計画。
営業のフォローアップデモの 2 日後、7 日後、14 日後の電話を、打ち合わせが終わる前に商談に作成。
カスタマーサクセス顧客と合意した日のオンボーディングセッションを、それぞれ状況を持つ ToDo として。
コンプライアンスと財務決まった日付に来る申告やレビューの期限を、担当者に割り当てて。
非営利団体大口寄付者へのお礼の電話や関係づくりの連絡を、シーズンを通じて計画。
サービスチームケースのクローズ後のフォローアップ確認を、顧客が希望した日に。

動作を決める設定

いずれもセットアップウィザードの項目とコンポーネントのプロパティなので、コードは一切不要です。

子オブジェクトの API 参照名（Child Object API Name）Task (ToDo): 選んだ日がそれぞれ Salesforce の ToDo として保存されます。relatedObjectApiName
関連項目の API 参照名（Relationship Field API Name）取引先、商談、ケース、カスタムオブジェクトでは WhatId (関連先)、取引先責任者とリードでは WhoId (名前)。relationshipFieldApiName
日付項目の API 参照名（Date Field API Name）ActivityDate (ToDo の期日)。dateFieldApiName
レコード名項目とデフォルトレコード名（Record Name Field and Default Record Name）Subject (件名) と、入力欄に最初から入っている件名。recordNameField、defaultRecordName
状況項目と状況の色（Status Field and Status Colors）Status (状況) と値ごとの色 (例: Completed:#22C55E)。statusField、statusColors
既定の項目値（Default Field Values）新しい ToDo すべてに入れるほかの項目 (例: Priority=High、割り当て先を指定する OwnerId)。defaultFieldValues
1 日に複数を許可（Allow Multiple Per Day）すでに ToDo がある日にも、もう 1 件追加できます。allowMultiplePerDay
レコード詳細のポップアップ（Record Details Pop-up）保存の前に、選んだ項目の入力フォームを開きます。内容は全日共通にも、日ごとに個別にもできます。recordForm
各日にレコード名を表示（Show Record Names in Each Day）カレンダーサイズが「大」または「全幅」のとき、各 ToDo の件名をその日に書き込みます。monthShowNames
「すべてのレコードを表示」と「レコードフィルター」（Show All Records and Record Filter）アプリケーションページやホームページで、すべての ToDo、または OwnerId=ME で自分の ToDo だけを表示するカレンダー。showAllRecords、recordFilter
設定名（Config Name）セットアップウィザードで保存した設定。これを設定すれば、ほかは空欄のままで構いません。configName
月表示のグリッドだけではありません。 「利用可能な表示」に予定一覧 (Agenda) を加えると、同じ ToDo が日ごとの一覧でも表示され、カレンダーからワンクリックで切り替えられます。5 つの表示をすべて見る。

よくある質問

Salesforce で複数の ToDo を一括作成するには?

MultiDatePick の Dates コンポーネントをレコードページに配置し、保存先のオブジェクトに ToDo を指定します。ToDo が必要な日をすべてクリックし、件名を入力して保存します。MultiDatePick が 1 日ごとに標準の Salesforce ToDo を 1 件ずつ作成し、それぞれに期日を設定してレコードに関連付けます。保存は 1 回だけで、フローも Apex も使いません。

パターンのない不規則な日付にも、Salesforce の ToDo を作成できますか?

はい。3 日、11 日、24 日のように必要な日をそのままクリックすれば、それぞれが ToDo になります。日付にパターンがある場合は、「繰り返しパターンを追加」ボタンで自動入力できます。毎週火曜、隔週、毎月の第 1 月曜や最終金曜といった具合です。

この方法で ToDo を作成できるのは、どのレコードページですか?

ToDo を関連付けられるレコードなら、どれでも使えます。取引先、商談、ケース、活動を許可したカスタムオブジェクトは関連先 (WhatId) で、取引先責任者とリードは名前 (WhoId) で紐づきます。取引先責任者のページでは、Salesforce がその取引先責任者の取引先も自動で設定するため、新しい ToDo は取引先にも表示されます。

新しい ToDo すべてに、同じ優先度、状況、任命先を設定できますか?

はい。「状況」の選択欄で、保存する ToDo の状況を設定します。それ以外の項目は「既定の項目値」で新しい ToDo すべてに入力できます。たとえば Priority=High、コメント欄の一文、特定のユーザーに割り当てるなら OwnerId にそのユーザーの ID を指定します。設定しなければ、Salesforce の通常の動作どおり、保存した人が任命先になります。

Salesforce の ToDo をカレンダーで表示できますか?

はい。レコードページでは、そのレコードの ToDo が状況の色でカレンダーに表示されます。アプリケーションページやホームページでは、「すべてのレコードを表示」をオンにして「レコードフィルター」に OwnerId=ME を設定すると、自分の ToDo のカレンダーになり、各日に件名が表示されます。日にカーソルを合わせれば詳細が表示され、予定一覧表示を加えれば一覧でも確認できます。
