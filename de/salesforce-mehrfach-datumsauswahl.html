Klicken, ziehen oder wiederholen: drei Wege, Termine zu wählen

Kombinieren Sie alle drei in einer Auswahl. Rückgängig und Alle löschen sind immer nur einen Klick entfernt.

1KlickenBeliebige einzelne Termine wählen, über den Monat verteilt.
2ZiehenÜber die Tage ziehen, um einen Zeitraum in einem Zug zu wählen.
3WiederholungsmusterWochentage, Wochenenden oder benutzerdefinierte Tage. Alle N Wochen. Das 1., 2., 3., 4. oder letzte Vorkommen im Monat, etwa der 2. und 4. Freitag oder der letzte Samstag.

Fünf Ansichten derselben Termindatensätze

Dieselben Datensätze, dasselbe Speichern. Die Standardansicht legen Sie mit View fest, die übrigen bieten Sie mit Available Views (Verfügbare Ansichten) an.

Welche Tage?

  • Ein Monat auf einen Blick, mit Statusfarbe an jedem Tag
  • Zum Auswählen klicken oder ziehen
  • Hover über einen Tag zeigt seine Datensätze
  • Die Standardansicht

Wie lange dauert jeder Zeitraum?

  • Tage nebeneinander
  • Ein Zeitraum erscheint als ein durchgehender Balken
  • Zoom auf Woche oder Monat; Fenster festgelegt über Timeline Window (Days) / Zeitachsenfenster (Tage)

Was steht diese Woche an?

  • Sieben Tage nebeneinander
  • Termindatensätze liegen in einem Ganztagsstreifen
  • Uhrzeiten ergänzen Sie mit der Komponente Date Time

Welche Tage sind am vollsten?

  • Eine Heatmap der Datensätze pro Tag
  • Volle Wochen auf einen Blick erkennen
  • Klick auf einen Tag öffnet diese Woche

Was steht als Nächstes an?

  • Die nächsten 60 Tage nach Datum
  • Beliebige Felder, ausgewählt über Agenda Fields (Agenda-Felder)
  • Ideal auf dem Smartphone oder in einem Übersichtsbereich

Mehrere Termine in einem Bildschirm-Flow auswählen

Ziehen Sie Dates auf einen Bildschirm und setzen Sie Config Name. Jedes Häkchen kommt aus Ihrer Konfiguration im Einrichtungsassistenten.

1Was Sie vorab brauchenEine Textsammlungsvariable für die Termine. Für Zeiträume zusätzlich eine Textvariable.
2PlatzierenSetzen Sie Config Name und ordnen Sie dann Selected Dates (Output) Ihrer Sammlung zu.
3Was herauskommtDie Termine in Ihrer Variablen, bereit für eine Schleife. Setzen Sie Parent Record Id, dann werden auch die Datensätze gespeichert.
AusgabeWas der Flow bekommt
Selected Dates (Output)Textsammlung mit ISO-Daten: ["2026-07-10","2026-07-14"]
Date Ranges JSON (Output)Benachbarte Tage zu Zeiträumen gruppiert. Erfordert aktiviertes Output Date Ranges as JSON.
Parse Date Entries from JSONMitgelieferte Flow-Aktion: macht aus dem JSON Einträge mit fromDate / toDate, die Sie in einer Schleife durchlaufen können.

Einstellungen nur für Flows bleiben aus, bis Sie sie aktivieren: Required, Show Inline (No Button) und Output Date Ranges as JSON. Alle Muster im Leitfaden Bildschirm-Flow.

Fragen zur Mehrfach-Datumsauswahl

Kurze Antworten. Mehr auf der FAQ-Seite.

Kann ein Datumsfeld in Salesforce mehrere Daten enthalten?

Nein. Ein Standard-Datumsfeld enthält ein Datum, ein Feldpaar einen Zeitraum. MultiDatePick speichert jeden Termin, den der Benutzer wählt, als verknüpften untergeordneten Datensatz des übergeordneten Datensatzes. So kann ein Datensatz beliebig viele Termine haben, jeden mit eigenem Status.

Wie wähle ich einen Zeitraum in einer LWC aus?

Platzieren Sie die MultiDatePick-Komponente Date auf der Seite und ziehen Sie über die Tage. Setzen Sie End Date Field API Name, dann werden benachbarte Tage als ein Datensatz mit Start- und Enddatum gespeichert: Montag bis Freitag ist ein Datensatz, nicht fünf. Keine eigene LWC nötig.

Kann ich in einem Bildschirm-Flow mehrere Termine auswählen?

Ja. Ziehen Sie die Komponente Date auf einen Flow-Bildschirm und setzen Sie Config Name. Selected Dates (Output) gibt jeden gewählten Termin als Textsammlung mit ISO-Daten zurück. Aktivieren Sie Output Date Ranges as JSON, und die Aktion Parse Date Entries from JSON liefert Von- und Bis-Daten, die Sie in einer Schleife durchlaufen können.

Können Benutzer wiederkehrende Termine wählen, etwa jeden zweiten Montag?

Ja. Die Schaltfläche Wiederholungsmuster hinzufügen wählt Wochentage, Wochenenden oder benutzerdefinierte Tage, wiederholt alle N Wochen und kann auf das 1., 2., 3., 4. oder letzte Vorkommen im Monat beschränkt werden, zwischen einem Start- und einem Enddatum.

Kann ich auf einer Experience Cloud-Site einen öffentlichen Terminkalender zeigen?

Ja. Platzieren Sie die Komponente Date auf einer Experience Cloud-Seite und setzen Sie Static Parent Record Id. Setzen Sie Existing Dates Mode auf readonly, um gespeicherte Termine zu zeigen, ohne dass Besucher sie ändern können, und aktivieren Sie Show In-Component Toast für Speichermeldungen.

Was kostet die MultiDatePick-Komponente Date?

MultiDatePick kostet $20 pro Benutzer und Monat, mit 30 Tagen kostenlosem Test ohne Kreditkarte. Die Komponenten Date, Date Time und Booking sind alle enthalten.
