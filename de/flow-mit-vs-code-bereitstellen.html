Einen Flow aus VS Code bereitstellen

Sie haben einen Starter-Flow aus dem Artikel zu Flow-Schleifen kopiert. So bringen Sie diesen Flow mit VS Code und der Salesforce CLI in Ihre Salesforce-Org. Das ist der Weg für Entwickler. Wenn Sie keinen Code-Editor anfassen möchten, folgen Sie dem Leitfaden Bildschirm-Flow: Komponente auf einen Bildschirm ziehen und Config Name setzen.

Was das bewirkt: Das kopierte XML ist ein fertiger Bildschirm-Flow (Screen Flow) mit eingebetteter MultiDatePick-Komponente, bereits mit einer sinnvollen Auswahl an Objekten und Feldern verbunden. Sie stellen ihn einmal bereit und benennen dann ein paar API-Namen passend zu Ihrer Org um. Beim ersten Mal dauert das etwa 15 Minuten, danach ein paar Minuten.

1. Was Sie brauchen

Drei kostenlose Tools. Einmal installiert, sind Sie für jede künftige Bereitstellung gerüstet:

  • Visual Studio Code: der Code-Editor.
  • Salesforce Extension Pack: fügt VS Code die SFDX-Befehle hinzu. Installieren Sie es über das Erweiterungen-Panel (Suche nach "Salesforce Extension Pack").
  • Salesforce CLI (sf): das Befehlszeilentool, über das die Bereitstellung läuft. Prüfen Sie die Installation, indem Sie sf version im Terminal von VS Code ausführen.

2. Einmalige Einrichtung

Überspringen Sie diesen Abschnitt, wenn Sie bereits in einem SFDX-Projekt arbeiten, das mit Ihrer Org verbunden ist.

A Org autorisieren

Verbinden Sie VS Code mit Ihrer Salesforce-Org. Öffnen Sie die Befehlspalette (Ctrl/Cmd + Shift + P) und führen Sie SFDX: Authorize an Org aus, oder führen Sie dies im Terminal aus:

sf org login web --alias myorg

Ein Browser öffnet sich; melden Sie sich an und bestätigen Sie. Verwenden Sie zuerst eine Sandbox oder eine Developer-Org, nicht die Produktion.

B Projekt öffnen oder erstellen

Wenn Sie ein SFDX-Projekt haben, öffnen Sie dessen Ordner in VS Code (File → Open Folder). Wenn nicht, erstellen Sie eines:

sf project generate --name multidatepick-flows
cd multidatepick-flows

Öffnen Sie diesen Ordner dann in VS Code. Im Explorer-Panel sollten Sie eine Struktur force-app/main/default/ sehen.

3. Das kopierte XML importieren

1 Flow-Datei erstellen

Klappen Sie im Explorer force-app/main/default/ auf und öffnen (oder erstellen) Sie den Ordner flows. Fügen Sie eine neue Datei mit dem Namen Ihres Flows und der Endung .flow-meta.xml hinzu, zum Beispiel On_Call_Rotation.flow-meta.xml. Der Name wird zum API-Namen des Flows, verwenden Sie also nur Buchstaben, Ziffern und Unterstriche.

Oder erstellen Sie sie direkt im integrierten Terminal von VS Code:

# Windows (PowerShell)
New-Item force-app/main/default/flows/On_Call_Rotation.flow-meta.xml -ItemType File -Force
# macOS / Linux
mkdir -p force-app/main/default/flows && touch force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

2 Einfügen und speichern

Fügen Sie das Starter-Flow-XML aus dem Artikel zu Flow-Schleifen in die neue Datei ein und speichern Sie (Ctrl/Cmd + S).

3 In Ihrer Org bereitstellen

Klicken Sie im Explorer mit der rechten Maustaste auf die Datei und wählen Sie SFDX: Deploy Source to Org, oder führen Sie dies im Terminal aus:

sf project deploy start --source-dir force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

Achten Sie im Output-Panel auf Deploy Succeeded. Meldet es einen Feld- oder Objektfehler, ist das zu erwarten. Der nächste Schritt behebt ihn.

4. Im Flow Builder abschließen

4 Eigene Objekt- und Feldnamen einsetzen

Gehen Sie in Ihrer Org zu Setup → Flows und öffnen Sie den Flow, den Sie gerade bereitgestellt haben. Suchen Sie die Elemente und Notizen mit der Markierung >>> UPDATE. Sie zeigen auf die API-Namen von Objekt und Feldern, von denen das Beispiel ausgeht. Ändern Sie jeden passend zu Ihrem eigenen Objekt, Datumsfeld und Lookup-Feld. Dann Speichern und Aktivieren.

Legen Sie den Flow jetzt auf eine Seite oder eine Schaltfläche oder führen Sie ihn direkt aus, und Benutzer können Termine auswählen.

Befehle im Überblick: 
sf org login web --alias myorg                 # authorize once
sf project generate --name multidatepick-flows  # only if you need a new project
sf project deploy start --source-dir force-app/main/default/flows/YOUR_FLOW.flow-meta.xml
Hängen Sie bei der CLI fest? Der CLI-Einrichtungsleitfaden von Salesforce erklärt Installation und Anmeldung im Detail.
