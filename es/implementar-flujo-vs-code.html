Implementar un flujo desde VS Code

Copiaste un flujo inicial del artículo sobre bucles en flujos. Así es como llevas ese flujo a tu organización de Salesforce con VS Code y Salesforce CLI. Este es el camino para desarrolladores. Si prefieres no tocar un editor de código, sigue la Guía de flujos de pantalla: coloca el componente en una pantalla y define Config Name (Nombre de configuración).

Qué hace esto: el XML copiado es un flujo de pantalla (Screen Flow) ya preparado que incluye el componente MultiDatePick, ya conectado a un conjunto razonable de objetos y campos. Lo implementas una vez y luego cambias algunos nombres de API para que coincidan con tu organización. La primera vez lleva unos 15 minutos; después, un par de minutos.

1. Lo que necesitas

Tres herramientas gratuitas. Instálalas una vez y estarás listo para cualquier implementación futura:

  • Visual Studio Code: el editor de código.
  • Salesforce Extension Pack: añade los comandos SFDX a VS Code. Instálalo desde el panel Extensiones (busca "Salesforce Extension Pack").
  • Salesforce CLI (sf): la herramienta de línea de comandos con la que se ejecuta la implementación. Comprueba que está instalada ejecutando sf version en el terminal de VS Code.

2. Configuración inicial (una sola vez)

Omite esta sección si ya trabajas en un proyecto SFDX conectado a tu organización.

A Autoriza tu organización

Conecta VS Code con tu organización de Salesforce. Abre la paleta de comandos (Ctrl/Cmd + Shift + P) y ejecuta SFDX: Authorize an Org, o ejecuta esto en el terminal:

sf org login web --alias myorg

Se abre un navegador; inicia sesión y aprueba el acceso. Usa primero un sandbox o una organización Developer, no producción.

B Abre o crea un proyecto

Si tienes un proyecto SFDX, abre su carpeta en VS Code (File → Open Folder). Si no, crea uno:

sf project generate --name multidatepick-flows
cd multidatepick-flows

Después abre esa carpeta en VS Code. Deberías ver una estructura force-app/main/default/ en el panel Explorer.

3. Importa el XML copiado

1 Crea el archivo del flujo

En el Explorer, despliega force-app/main/default/ y abre (o crea) la carpeta flows. Añade un archivo nuevo con el nombre de tu flujo y la extensión .flow-meta.xml, por ejemplo On_Call_Rotation.flow-meta.xml. El nombre pasa a ser el nombre de API del flujo, así que usa solo letras, números y guiones bajos.

O créalo directamente desde el terminal integrado de VS Code:

# Windows (PowerShell)
New-Item force-app/main/default/flows/On_Call_Rotation.flow-meta.xml -ItemType File -Force
# macOS / Linux
mkdir -p force-app/main/default/flows && touch force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

2 Pega y guarda

Pega en el archivo nuevo el XML del flujo inicial que copiaste del artículo sobre bucles en flujos y guarda (Ctrl/Cmd + S).

3 Implementa en tu organización

Haz clic con el botón derecho en el archivo en el Explorer y elige SFDX: Deploy Source to Org, o ejecuta esto en el terminal:

sf project deploy start --source-dir force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

Busca Deploy Succeeded en el panel Output. Si informa de un error de campo u objeto, es lo esperado. El paso siguiente lo corrige.

4. Termina en Flow Builder

4 Sustituye los nombres de objeto y de campo por los tuyos

En tu organización, ve a Configuración → Flujos y abre el flujo que acabas de implementar. Busca los elementos y notas marcados con >>> UPDATE. Señalan los nombres de API de objeto y campo que suponía el ejemplo. Cambia cada uno para que coincida con tu propio objeto, tu campo de fecha y tu búsqueda. Después haz clic en Guardar y Activar.

Ahora coloca el flujo en una página o en un botón, o ejecútalo directamente, y los usuarios podrán empezar a seleccionar fechas.

Resumen de comandos: 
sf org login web --alias myorg                 # authorize once
sf project generate --name multidatepick-flows  # only if you need a new project
sf project deploy start --source-dir force-app/main/default/flows/YOUR_FLOW.flow-meta.xml
¿Atascado con la CLI? La guía de configuración de la CLI de Salesforce explica en detalle la instalación y el inicio de sesión.
