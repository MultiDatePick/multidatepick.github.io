Clic, arrastre o repetición: tres formas de elegir fechas

Combina las tres en una misma selección. Deshacer y Borrar todo están siempre a un clic.

1ClicElige fechas sueltas, repartidas por el mes.
2ArrastreArrastra sobre los días para seleccionar un rango de fechas de una vez.
3Patrón recurrenteDías laborables, fines de semana o días personalizados. Cada N semanas. La 1.ª, 2.ª, 3.ª, 4.ª o última aparición en el mes, como el 2.º y 4.º viernes o el último sábado.

Cinco vistas de los mismos registros de fechas

Mismos registros, misma forma de guardar. Define la vista predeterminada con View y ofrece las demás con Available Views (Vistas disponibles).

¿Qué días?

  • Un mes cada vez, con el color de estado en cada día
  • Haz clic o arrastra para elegir
  • Pasa el cursor sobre un día para ver sus registros
  • La predeterminada

¿Cuánto dura cada rango?

  • Fechas en la parte superior
  • Un rango de fechas se dibuja como una sola barra continua
  • Zoom de Semana o Mes; ventana definida por Timeline Window (Days) (Ventana de la línea de tiempo en días)

¿Qué hay esta semana?

  • Siete días uno junto a otro
  • Los registros de fecha se colocan en una franja de todo el día
  • Añade horas con el componente Date Time

¿Qué días tienen más actividad?

  • Un mapa de calor de registros por día
  • Detecta de un vistazo las semanas más cargadas
  • Haz clic en un día para abrir esa semana

¿Qué viene ahora?

  • Los próximos 60 días por orden de fecha
  • Los campos que elijas con Agenda Fields (Campos de Agenda)
  • Ideal en el móvil o en un panel de resumen

Un componente, cinco presentaciones. Las demos usan datos de citas de ejemplo; un calendario Date dibuja las mismas vistas a partir de sus propios registros de fechas.

Páginas de registro, de aplicación, de inicio y de Experience Cloud. Las fechas se guardan como registros secundarios sin ningún flujo.

2ColócaloEn Lightning App Builder, arrastra Dates a la página y define Config Name. Es el único ajuste.
3Qué obtienesUn registro por fecha, o por rango, vinculado al registro de la página. Load Existing Dates (Precargar fechas existentes) muestra lo que ya está guardado.
PáginaQué configuras

Páginas de aplicación y de inicioConfig Name más Static Parent Record Id.
Experience CloudConfig Name más Static Parent Record Id. Activa Show In-Component Toast.

Elige varias fechas en un flujo de pantalla

Arrastra Dates a una pantalla y define Config Name. Todas las casillas salen de tu configuración del asistente.

1Qué necesitas antesUna variable de colección de texto para las fechas. También una variable de texto si quieres rangos.
2ColócaloDefine Config Name y asigna Selected Dates (Output) a tu colección.
3Qué obtienesLas fechas en tu variable, listas para recorrer en un bucle. Define Parent Record Id y también guarda los registros.
SalidaQué recibe el flujo
Selected Dates (Output)Colección de texto con fechas ISO: ["2026-07-10","2026-07-14"]
Date Ranges JSON (Output)Fechas seguidas agrupadas en rangos. Requiere activar Output Date Ranges as JSON.
Parse Date Entries from JSONAcción de flujo incluida: convierte el JSON en entradas fromDate / toDate que puedes recorrer en un bucle.

Los ajustes exclusivos de flujos quedan desactivados salvo que los actives: Required, Show Inline (No Button) y Output Date Ranges as JSON. Todos los patrones, en la Guía de flujos de pantalla.

Preguntas sobre el selector de varias fechas

Respuestas breves. Más en la página de preguntas frecuentes.

¿Un campo de fecha de Salesforce puede guardar varias fechas?

No. Un campo de fecha estándar guarda una fecha, y un par de campos guarda un rango. MultiDatePick guarda cada fecha que elige el usuario como un registro secundario relacionado con el principal, así que un registro puede tener tantas fechas como quieras, cada una con su propio estado.

¿Cómo selecciono un rango de fechas en un LWC?

Coloca el componente Date de MultiDatePick en la página y arrastra sobre los días. Define End Date Field API Name (Campo de fecha de fin) y los días seguidos se guardan como un solo registro con fecha de inicio y de fin, así que de lunes a viernes es un registro, no cinco. Sin crear un LWC personalizado.

¿Puedo elegir varias fechas en un flujo de pantalla?

Sí. Arrastra el componente Date a una pantalla de flujo y define Config Name. Selected Dates (Output) devuelve todas las fechas elegidas como una colección de texto con fechas ISO. Activa Output Date Ranges as JSON y la acción Parse Date Entries from JSON te da fechas de inicio y fin que puedes recorrer en un bucle.

¿Los usuarios pueden elegir fechas recurrentes, como un lunes sí y otro no?

Sí. El botón Añadir patrón recurrente selecciona días laborables, fines de semana o días personalizados, se repite cada N semanas y puede limitarse a la 1.ª, 2.ª, 3.ª, 4.ª o última aparición en el mes, entre una fecha de inicio y una de fin.

¿Puedo mostrar un calendario público de fechas en un sitio de Experience Cloud?

Sí. Coloca el componente Date en una página de Experience Cloud y define Static Parent Record Id. Pon Existing Dates Mode (Modo de precarga) en readonly para mostrar las fechas guardadas sin que los visitantes puedan cambiarlas, y activa Show In-Component Toast (Mostrar aviso en el componente) para los mensajes de guardado.

¿Cuánto cuesta el componente Date de MultiDatePick?

MultiDatePick cuesta US$20 por usuario al mes, con una prueba gratuita de 30 días y sin tarjeta. Los componentes Date, Date Time y Booking están todos incluidos.
