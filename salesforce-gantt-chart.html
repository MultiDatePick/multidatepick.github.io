Gantt chart: Salesforce Gantt Chart: No-Code Project Plans on Any Object

Every project, phase and task on one Salesforce chart, built from your own records. Link the tasks, drag one, and everything waiting on it moves too. An admin sets it up in the Setup Wizard, with no code.

Is there a Gantt chart for Salesforce?

Yes. MultiDatePick adds a Gantt view to any Salesforce object with a start date and an end date, set up in a wizard with no code. Tasks group into phases and projects with health and milestones, links move the waiting tasks when one slips, and a critical path, slack and planned dates show what can still slip and what cannot.

3 steps, 0 lines of code

See every project at a glance

Projects sit at the top and each one opens into its phases and tasks, so a director sees the portfolio and a project lead sees the detail on the same chart.

Projects, phases, tasksA Project field and a Phase field turn a flat list of records into an outline.
Health with a reasonA dot, the word and why: 6 days behind plan, 2 tasks overdue, Starts Dec 7.
Summary cardsProjects, On track, At risk, Late vs plan (with planned dates) and Milestones this month, counted for you.
MilestonesA ticked checkbox draws a dot on the day, with a check once reached.
Percent doneA number field fills each bar. Phases and projects roll it up, weighted by days.

Who does the workOn a Resource Booking calendar, the resource each task is booked on shows as initials on wider bars and in full in an Owner column.

Project health, with the reason

Each project’s health is worked out from its tasks, and the reason sits under the word, so a status meeting can skip straight to what to do.

Already track health yourself? Pick your Health field and each project shows the value most of its tasks hold, in your calendar’s color for it. Those projects have no reason line, and the On track, At risk and Late vs plan cards count only worked-out health.

Task dependencies, critical path and baseline

Link the tasks once. A slip then moves everything that depends on it by just enough, on working days only.

Link tasks with a lookup or a link object

A Waits on lookup covers a task that waits on one other. For several, use a link object of your own: one record per link, with a lookup to each task. Only a link object adds a type and a lag in working days; a Waits on lookup always means after it ends, and a link drawn on the chart starts out that way, with no lag.

Link typeThe waiting taskExample
After it endsStarts once the first task has endedMovers start after Pack the office ends
When it startsCan start once the first task startsNetwork and phones starts when packing starts
When it endsCan end once the first task endsNetwork and phones ends when Movers ends
LagAdds working days to the link; a negative lag lets the two overlap2 leaves two free working days between them

Each waiting bar starts with a small notch in the color of the task it waits on, and a bar’s links show as soft curves when you hover over it or tab to it. A project that waits on another says so: after Office Move.

Drag one task, and the tasks waiting on it follow

Drag a bar later and every task that waits on it moves by the least it needs, never earlier, so dates people set by hand stay put. A message says what moved:

Moved Pack the office and 3 waiting tasks. Undo puts them all back.

Teams that set every date by hand, like a roadmap, set When a task moves to Only draw the links: the links still show, and nothing else moves.

Working days, weekends and closures

Skip weekends is on from the start: pushes, lag and the Days column skip Saturday and Sunday, so a three-day task pushed to a Friday ends on Tuesday. Office closures from your Blocked Dates records, and days a resource is closed, are skipped too.

Critical path and slack

Press Critical path and the chain of tasks that decides each project’s finish stands out, over every link type and lag, on working days. Each linked task’s hover card shows its room: Can slip 3 workdays or No slack: on the critical path. With planned dates set, a task whose chain now ends after its project’s planned end says Behind by 2 workdays. The Slack column shows it for every task.

Planned dates and a baseline

Point two date fields at the original plan and every bar gets a thin plan bar under it. A task that slipped shows +2 days, and its project says how many days it is behind plan. Set baseline copies the current dates into the plan after asking first, and Show plan turns the plan bars on and off.

Edit the plan right on the chart

With Edit Mode on, the chart is the editor, and every change saves to the record itself.

Move and resize

Drag a bar to move it, or pull its end to change its length. The tasks that wait on it move with it.

Draw a link

Drag the round handle at the end of a bar onto the task that waits on it. A link that would make a loop is refused.

Set percent done

Drag the grip inside a bar, in steps of 5. The phase and project totals follow.

Add a task

Click Add task under a phase, or drag across the days it takes.

Undo the whole move

Undo puts back the task you moved and every task it pushed. It covers links, percent done and baselines too.

Remove a link

A task’s hover card lists the tasks it waits on, each with Remove link.

Add task uses your own form

It opens the Record details pop-up the calendar already uses, filled in with the row’s phase, project or resource and the days you dragged across, and saves with your name rules and Default Field Values. With no pop-up set, Salesforce’s own New window opens instead.

Columns, sorting and time span

Pick the columns, sort by any of them, and slide the horizon from one week to half a year.

  • Up to six columns beside each task name: Start, End, Days and Waits on, plus Done, Owner, Slack, Planned start, Planned end, Variance, Health and Project once the matching setting is in place
  • Any field on your object can be a column too, such as a budget or a priority
  • Click a column head to sort; tasks sort within their phase
  • The horizon slider shows 1 to 26 weeks: short spans show every day, long ones show weeks
  • Arrows step through time, and Today jumps back to now
  • Fit project (Fit all projects on a chart with projects) frames the whole plan; press it again to go back to where you were
  • Collapse a phase or a project to one row with its own bar and percent done

Set up in minutes, with nothing required

On the Setup Wizard’s Views tab, tick Offer the Gantt view and it already works: each record is a bar from its date to its end date. Every option after that adds something you can see.

  • Zero required fields. Each Gantt setting has an (i) help with an example.
  • It picks for you only when it is sure. If exactly one field on your object fits a box, the wizard fills it in and marks it Picked for you.
  • A live preview follows every option, from phases to links.
  • No field yet? The Missing a field? bar opens Object Manager for your object, and Refresh fields fills the box once the field exists.

Salesforce Gantt chart questions

Short answers to what people search.

Is there a Gantt chart for Salesforce?

Yes. MultiDatePick adds a Gantt view to any Salesforce object with a start date and an end date, set up in a wizard with no code. Tasks group into phases and projects with health and milestones, links move the waiting tasks when one slips, and a critical path, slack and planned dates show what can still slip and what cannot.

How do I create a Gantt chart in Salesforce without code?

Open the MultiDatePick Setup Wizard, choose the object that holds your tasks and its start and end date fields, and tick Offer the Gantt view on the Views tab. Add the calendar to a Lightning page and paste the Config Name. Phases, projects, percent done, milestones, links and planned dates are optional fields you add when you want them.

Can a Salesforce Gantt chart show task dependencies?

Yes. Link tasks with a Waits on lookup, or with your own link object when a task waits on several others. A link object can also give each link a type (after it ends, when it starts or when it ends) and a lag in working days; a Waits on lookup always means after it ends. Drag a task and every task that waits on it moves too.

Does the Gantt view show the critical path?

Yes. The Critical path button highlights the tasks with no slack, where any delay moves the finish date. Each linked task’s hover card says how many workdays it can slip, and a Slack column can list it for every task.

Can I compare planned dates with actual dates in a Salesforce Gantt chart?

Yes. Choose two date fields for the planned start and end. Each bar gets a plan bar under it and shows +N days when it slipped, each project shows how many days it is behind plan, and Set baseline saves the current dates as the plan.

Which Salesforce objects can the Gantt view use?

Any standard or custom object with a date field for the start and one for the end, such as your own Project Task object. Phases and projects come from fields on the same records (a picklist, a text field or a lookup), and links come from a lookup or your own link object.

Does the Gantt view skip weekends and holidays?

Yes. Skip weekends is on by default, so pushes, lag and day counts skip Saturday and Sunday. Office closures from Blocked Dates and the days a resource is closed are skipped too. Turn Skip weekends off when every day is a working day.

How many tasks can the Gantt view handle?

Hundreds. It was measured with 511 tasks and 474 links: the first draw took about 160 milliseconds, and a sort, a collapse or a new horizon about a tenth of a second, because a long chart draws only the rows near the screen.

Does the Gantt view cost extra?

No. It is part of MultiDatePick, $20 per user per month with every feature in one plan and a 30-day free trial. The Gantt view is one of the calendar’s views, turned on per page in the Setup Wizard.
