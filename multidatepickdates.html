Multi-date picker questions

Short answers. More on the FAQ page.

Can a Salesforce date field hold multiple dates?

No. A standard Date field holds one date, and a pair of fields holds one range. MultiDatePick saves every date the user picks as a related child record of the parent, so one record can have any number of dates, each with its own status.

How do I select a date range in an LWC?

Drop the MultiDatePick Date component on the page and drag across the days. Set End Date Field API Name and adjacent days save as one record with a start and an end date, so Monday to Friday is one record, not five. No custom LWC to build.

Can I pick multiple dates in a Screen Flow?

Yes. Drag the Date component onto a Flow screen and set Config Name. Selected Dates (Output) returns every picked date as a Text collection of ISO dates. Turn on Output Date Ranges as JSON and the Parse Date Entries from JSON action gives you loopable from and to dates.

Can users pick recurring dates, like every other Monday?

Yes. The Add Recurring Pattern button selects weekdays, weekends or custom days, repeats every N weeks, and can limit to the 1st, 2nd, 3rd, 4th or last occurrence in the month, between a start and an end date.

Can I show a public calendar of dates on an Experience Cloud site?

Yes. Place the Date component on an Experience Cloud page and set Static Parent Record Id. Set Existing Dates Mode to readonly to show saved dates without letting visitors change them, and turn on Show In-Component Toast for save messages.

How much does the MultiDatePick Date component cost?

MultiDatePick is $20 per user per month with a 30-day free trial and no card required. The Date, Date Time and Booking components are all included.
