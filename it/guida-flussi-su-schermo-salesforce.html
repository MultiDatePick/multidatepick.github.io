Guida ai flussi su schermo

Inserisci un calendario MultiDatePick in qualsiasi flusso su schermo (Screen Flow) Salesforce. Trascina il componente su una schermata, imposta Config Name e hai finito.

Nessun Apex richiesto
  1. 1Salva una configurazioneConfigurazione guidata o Config Library
  2. 2Trascinala su una schermataCerca MultiDatePick
  3. 3Imposta Config NameSalva, esegui il debug, attiva

Una sola proprietà: Config Name

Crea la configurazione una volta nella configurazione guidata, oppure importane una dalla Config Library. Nel flusso imposti una sola proprietà e il componente carica il resto.

  • Apri una schermata
  • →
  • Cerca MultiDatePick
  • →
  • Trascina Booking, Date o Date Time
  • →
  • Nome configurazione (Config Name)
  • →
  • Salva

Ogni casella di controllo arriva dalla configurazione. Con Config Name impostato non tocchi mai una casella di controllo in Flow Builder. Le proprietà di testo e numeriche che compili sulla schermata sostituiscono quelle della configurazione.

Salvare su un record

Collega Parent Record Id al record per cui viene eseguito il flusso, ad esempio {!recordId} o il risultato di un Ottieni record. Il componente salva quindi i suoi record collegati a quel record padre. Su Date e Date Time, lascialo vuoto e la selezione passa invece al flusso.

Crealo da un flusso vuoto

Cinque minuti in Flow Builder. Niente da distribuire: lo provi con Esegui debug.

1. Nuovo flusso su schermo

Imposta, Flussi, Nuovo flusso, Flusso su schermo, Crea.

2. Aggiungi una schermata

Aggiungi un elemento Schermata all'area di lavoro.

3. Trascina il componente

Cerca MultiDatePick nell'elenco dei componenti e trascinalo sulla schermata.

4. Imposta Config Name

Digita il nome della configurazione esattamente come l'ha salvato la configurazione guidata. Collega Parent Record Id se i record appartengono a un record padre.

5. Salva ed esegui il debug

Fai clic su Esegui debug, scegli date o fasce orarie e verifica che i record siano stati creati. Poi fai clic su Attiva e aggiungi il flusso a una pagina record, a un pulsante azione o a un sito Experience Cloud.

Cosa riceve il flusso

Booking salva da solo le sue prenotazioni. Date e Date Time passano la selezione al flusso, oppure la salvano da soli quando è impostato Parent Record Id.

Nessun Apex richiesto: le azioni di flusso già pronte

Non scrivi mai Apex. Per trasformare il JSON di Date o Date Time in record, usa i tre elementi inclusi nel pacchetto. Compaiono in Flow Builder come qualsiasi azione standard.

  • Parse Date Entries from JSON
  • →
  • Ciclo sulle voci
  • →
  • Crea record, uno per voce
Azione di flusso Parse Date Entries from JSON

Cercala in Azione. Passale Date Ranges JSON o Dates With Times JSON. Riconosce da sola se si tratta di sole date o di date e orari.

Classe: MultiDatePickParser

Tipo di dati MultiDatePickEntryCollection

Ciò che restituisce l'azione. Memorizzalo in una variabile definita da Apex ed esegui un ciclo su data.

  • data: le voci su cui eseguire il ciclo
  • totalCount: quante sono
  • success, errorMessage: per un elemento Decisione
Tipo di dati MultiDatePickEntry

Una voce, la tua variabile di ciclo. Mappala in Crea record.

  • fromDate, toDate: l'intervallo (uguali per un solo giorno)
  • startTime, endTime: solo Date Time
  • id: numero della voce

Date Ranges JSON (Date)

{ "data": [
  { "id": 1, "fromDate": "2026-02-10", "toDate": "2026-02-12" },
  { "id": 2, "fromDate": "2026-02-15", "toDate": "2026-02-15" }
] }

Dates With Times JSON (Date Time)

{ "data": [
  { "id": 1, "fromDate": "2026-02-10", "toDate": "2026-02-10",
    "startTime": "09:00", "endTime": "17:00" }
] }

Appendice: mappare le proprietà a mano

Solo se non usi Config Name. Flow Builder elenca le proprietà in ordine alfabetico e mostra gli elenchi di selezione come Conflict Behavior come semplici caselle di testo: per questo Config Name è il percorso più semplice. Per una schermata Booking, imposta queste:

Resource Name FieldIl campo mostrato come nome di ciascuna risorsaresourceNameField
Campo capacità (Capacity Field)Quante prenotazioni accetta una risorsa allo stesso tempo. Le fasce mostrano 3/5 e si chiudono quando sono piene.capacityField
Booking Object API NameL'oggetto in cui viene salvata ogni prenotazioneresourceBookingObject

Comportamento conflitto (Conflict Behavior)Digita block (predefinito), skip o allowconflictBehavior

Qui le caselle di controllo le imposti tu. Senza Config Name, ogni casella di controllo (Required, Show Inline, Output Date Ranges as JSON e le altre) corrisponde a ciò che selezioni sulla schermata.
