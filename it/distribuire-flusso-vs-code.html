Distribuire un flusso da VS Code

Hai copiato un flusso iniziale dall'articolo sui cicli nei flussi. Ecco come portarlo nella tua organizzazione Salesforce con VS Code e Salesforce CLI. Questo è il percorso per sviluppatori. Se preferisci non usare un editor di codice, segui la Guida ai flussi su schermo: trascina il componente su una schermata e imposta Config Name.

Cosa fa: l'XML copiato è un flusso su schermo (Screen Flow) già pronto che incorpora il componente MultiDatePick, già collegato a un insieme sensato di oggetti e campi. Lo distribuisci una volta, poi rinomini alcuni nomi API in base alla tua organizzazione. Servono circa 15 minuti la prima volta, un paio di minuti le volte successive.

1. Cosa ti serve

Tre strumenti gratuiti. Installali una volta e sei pronto per ogni distribuzione futura:

  • Visual Studio Code: l'editor di codice.
  • Salesforce Extension Pack: aggiunge i comandi SFDX a VS Code. Installalo dal pannello Estensioni (cerca "Salesforce Extension Pack").
  • Salesforce CLI (sf): lo strumento da riga di comando con cui avviene la distribuzione. Verifica che sia installato eseguendo sf version nel terminale di VS Code.

2. Configurazione iniziale (una sola volta)

Salta questa sezione se lavori già in un progetto SFDX collegato alla tua organizzazione.

A Autorizza la tua organizzazione

Collega VS Code alla tua organizzazione Salesforce. Apri il riquadro comandi (Ctrl/Cmd + Shift + P) ed esegui SFDX: Authorize an Org, oppure esegui questo comando nel terminale:

sf org login web --alias myorg

Si apre un browser: accedi e approva. Usa prima una sandbox o un'organizzazione Developer, non la produzione.

B Apri o crea un progetto

Se hai un progetto SFDX, apri la sua cartella in VS Code (File → Open Folder). Altrimenti creane uno:

sf project generate --name multidatepick-flows
cd multidatepick-flows

Poi apri quella cartella in VS Code. Nel pannello Explorer dovresti vedere la struttura force-app/main/default/.

3. Importa l'XML copiato

1 Crea il file del flusso

Nell'Explorer, espandi force-app/main/default/ e apri (o crea) la cartella flows. Aggiungi un nuovo file con il nome del tuo flusso e l'estensione .flow-meta.xml, ad esempio On_Call_Rotation.flow-meta.xml. Il nome diventa il nome API del flusso, quindi usa solo lettere, numeri e trattini bassi.

Oppure crealo direttamente dal terminale integrato di VS Code:

# Windows (PowerShell)
New-Item force-app/main/default/flows/On_Call_Rotation.flow-meta.xml -ItemType File -Force
# macOS / Linux
mkdir -p force-app/main/default/flows && touch force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

2 Incolla e salva

Incolla nel nuovo file l'XML del flusso iniziale che hai copiato dall'articolo sui cicli nei flussi e salva (Ctrl/Cmd + S).

3 Distribuisci nella tua organizzazione

Fai clic con il pulsante destro sul file nell'Explorer e scegli SFDX: Deploy Source to Org, oppure esegui questo comando nel terminale:

sf project deploy start --source-dir force-app/main/default/flows/On_Call_Rotation.flow-meta.xml

Controlla nel pannello Output che compaia Deploy Succeeded. Se segnala un errore su un campo o un oggetto, è normale: il passaggio successivo lo risolve.

4. Completa in Flow Builder

4 Inserisci i nomi dei tuoi oggetti e campi

Nella tua organizzazione, vai su Imposta → Flussi e apri il flusso appena distribuito. Cerca gli elementi e le note contrassegnati con >>> UPDATE: indicano i nomi API di oggetti e campi ipotizzati dall'esempio. Cambia ciascuno in base al tuo oggetto, al tuo campo data e al tuo campo di ricerca. Poi fai clic su Salva e Attiva.

Ora aggiungi il flusso a una pagina o a un pulsante, oppure eseguilo direttamente, e gli utenti possono iniziare a selezionare le date.

Riepilogo dei comandi: 
sf org login web --alias myorg                 # authorize once
sf project generate --name multidatepick-flows  # only if you need a new project
sf project deploy start --source-dir force-app/main/default/flows/YOUR_FLOW.flow-meta.xml
Bloccato con la CLI? La guida all'installazione della CLI di Salesforce spiega in dettaglio installazione e login.
